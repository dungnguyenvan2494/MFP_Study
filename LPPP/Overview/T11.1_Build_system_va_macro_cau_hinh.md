# T11.1 — Build system & macro cấu hình

Nguồn: `lppp_s800/{Makefile, Makefile-cfg, Makefile-lib-cfg, Makefile-rules, Makefile-os, build_lppp.sh}`,
`lppp_s800/Application/Makefile-cfg`, `lppp_s800/ApplicationKM/Makefile-cfg`.

---

## 1. Điểm vào build: `build_lppp.sh <board> [clean|update]`

```
./build_lppp.sh es       → BOARD=s800es    (S800 ES board — production)
./build_lppp.sh emu      → BOARD=s800emu   (Emu800)
  egl/eglz/dnbmlk/spa/eglb/... → các board họ Eagle/Deneb/Sparrow/Helios/Minerva
```
- `makeLppp`: `rm -rf output`, `make CROSS_COMPILE=s800-r4- --no-print-directory`, copy `mvri.bin → output/<board>/`.
- Toolchain prefix = **`s800-r4-`** (GCC bare-metal ARM, ví dụ `s800-r4-gcc`).
- Không tham số `LPDDR4_FREQ` (comment: "LPPP tự chọn theo tần số LPDDR param").

---

## 2. Kiến trúc Makefile (đệ quy theo submodule)

```
Makefile                (TARGETNAME = mvri, LDLIBS += lib/libpmu_r4.a)
├── Makefile-cfg          → ARCH=quartz, ASIC=asic, ASIC_REV=a0, ENABLE_DEBUG=1,
│   └── Makefile-lib-cfg    HAVE_UART=1, USE_THUMBCODE=1, OPT=2, IPV6=1, IGMP=1,
│                           CPU_LITTLE_ENDIAN=1, NETSTACK=lwipv6, MRVL_FILTER_ENABLED=1,
│                           WITH_BSD_SOCKETS=1, heap SYSTEM 23K / APP 3K, stack SYSTEM 1600 / APP 2048
├── Makefile-rules        → luật build chung; -DARCH_quartz -DMODE_$(MODE) -DMV_{HAL,SYS,APP,OSNET}_LAYER
├── Makefile-os           → ARMCC = $(PREFIXCC)gcc; -mcpu=cortex-r4; -mthumb -mthumb-interwork
├── Makefile-lib          → libbase (build sẵn thành .a)
└── mỗi thư mục con có Makefile + Makefile-cfg riêng:
    Application/  ApplicationKM/  ApplicationMrvl/  Sys/  Netstack/  Hal/  Os/
```
- `ALLSUBMODULES = $(patsubst %/,%,$(dir $(wildcard */Makefile)))` — auto-discover submodule bằng sự hiện diện `<dir>/Makefile`.
- `SUBMODULES` mặc định = `ALLSUBMODULES` (build tất cả). Output: `mvri.elf` → `mvri.bin` → `mvri.asm` (+ `.vhx`, `.h` C-array).
- `CCFLAGSFILE` (`cc<flagsfile>`) — cache cờ compile; rebuild khi Makefile đổi.

## 3. Macro cấu hình quan trọng (`-D...`)

### 3.1 Kiến trúc / nền tảng
| macro | giá trị | nguồn |
|-------|---------|-------|
| `ARCH_quartz` | luôn (ARCH=quartz) | `Makefile-rules:304` |
| `MODE_<MODE>` | `MODE` (release/debug?) | `Makefile-rules:309` |
| `-mcpu=cortex-r4`, `-mthumb -mthumb-interwork` | CPU R4, Thumb code | `Makefile-os` |
| `CPU_LITTLE_ENDIAN=1` | little-endian | `Makefile-cfg` |
| `MV_HAL_LAYER` / `MV_SYS_LAYER` / `MV_APP_LAYER` / `MV_OSNET_LAYER` | phân lớp | `Makefile-rules:78-91` |
| `ASIC=asic`, `ASIC_REV=a0` | → include path `Hal/quartz/asic/a0/...` | `Makefile-cfg` |
| `BUILD_r4` | (từ toolchain/định nghĩa khác — T8.1 `mc_configure_dram` `ddr_clk=0` khi `BUILD_r4`) | INFERENCE: set bởi `s800-r4-` toolchain hoặc `Makefile-os` |
| `FLEX_quartz` | (T8.1) — **KHÔNG** thấy trong Makefile ⇒ nhánh `#ifdef FLEX_quartz` **không build** cho S800 | INFERENCE |

### 3.2 Netstack (`Makefile-lib-cfg:35` `NETSTACK := lwipv6`)
| macro | ý nghĩa |
|-------|---------|
| `NETSTACK_lwipv6` | (từ tên) — chọn stack lwIPv6 |
| `ENABLE_IP_V6_SUPPORT`, `LWIP_IPV6=1` | `IPV6_SUPPORT=1` → `Makefile-rules:158` |
| `ENABLE_IGMP_SUPPORT` | `IGMP_SUPPORT=1` → `:166` |
| `ENABLE_MAC_FILTERING` | `MAC_FILTERING_ENABLE=0` → **KHÔNG** |

### 3.3 Filter / socket (`Makefile-lib-cfg`)
| macro | build? |
|-------|--------|
| `MRVL_FILTER_ENABLED` | ✅ (`:42 := 1`) — bật SysFilter (T5.2) |
| `ENABLE_SECOND_FILTER_STAGE` | ✅ (`:41 := 1`) — bật STAGE_2 (T5.2) |
| `MRVL_BSD_SOCKETS_ENABLED` | ✅ (`WITH_BSD_SOCKETS=1` → `:309`) — `appSendUdpPacket` dùng socket (T5.6) |

### 3.4 Proxy (`Application/Makefile-cfg:58-105`)
| `ENABLE_*` | → `-D` | build? |
|-----------|--------|--------|
| `ENABLE_SNMP_PROXY` | `SNMP_PROXY` | ✅ (T5.4) |
| `ENABLE_LLMNR_PROXY` | `LLMNR_PROXY` | ✅ (T5.3) |
| `ENABLE_NBNS_PROXY` | `NBNS_PROXY` | ✅ (T5.3) |
| `ENABLE_WAKE_SERVICE_PROXY` | `WAKE_SERVICE_PROXY` | ✅ (T5.4 — SSDP/WSD/SLP) |
| `ENABLE_SIMPLE_MDNS_PROXY` | `SIMPLE_MDNS_PROXY` | ✅ (T5.3) |
| `ENABLE_MDNS_PROXY` (bonjour) | `MDNS_PROXY` | ❌ (comment out — "not used anymore", T5.6) |
| `ENABLE_SLP_PROXY` (openslp) | `SLP_PROXY` | ❌ (comment out, T5.6) |

⇒ Khớp chính xác các phát hiện T5.3/T5.4/T5.6: SNMP + LLMNR + NBNS + wake-service + simple-mdns bật; bonjour-mdns + openslp tắt.

### 3.5 Debug
| macro | build? |
|-------|--------|
| `ENABLE_DEBUG=1` → `AR_DEBUG`/`APP_DEBUG` | ✅ (`ENABLE_DEBUG := 1` toàn cục + KM) |
| `HAVE_UART=1` | ✅ → UART debug (T7.6) |
| `HAVE_CMD` | ❌ (comment `Makefile-rules:213`) → console `app_cmdproc`/gpio-cmd/int-cmd **không build** (T7.3/T7.5/T7.6) |
| `RUN_CODE_CHECKS`, `RUN_DOXYGEN`, `PRINTVIACONTENT` | 0 |


## 4. Include path (`ApplicationKM/Makefile-cfg`)
Auto-thu module path từ `wildcard`:
```
APP_MODULE_PATHS = dir(Application/*/*.h) + dir(ApplicationMrvl/*/*.h) + dir(ApplicationKM/*.h)
SYS_MODULE_PATHS = dir(Sys/*/*.h)
+ Os/freertos/include, Netstack/lwipv6/src/include{,/lwip,/ipv4,/ipv6},
  Netstack/lwipv6/portable{,/arch}, Hal/quartz/{src,interrupt/include,cpu/include,asic/a0/include}, Hal/inc,
  Os/freertos/portable/GCC/quartz
```
⇒ Mọi header trong `Application*/`, `ApplicationKM/`, `Sys/*/` đều tự động thành `-I`. Đây là lý do các `#include "LPPP_inc.h"`, `"base_api.h"`… không cần path.

## 6. Sản phẩm build
```
mvri.elf   → mvri.bin (nạp QSPI)   → mvri.asm (disasm)
           → mvri.vhx (verilog hex, mô phỏng)
           → mvri.h   (C array, nhúng)
           → mvri_nochksum.bin / mvri_<tooltype>.bin (có/không checksum)
+ map.txt (MAPFILE), *.log (LOGFILE), rammap (RAMMAPFILE)
```
`TARGETNAME_quartz = mvri` (Marvell Reference Image?).

## 7. FACT / INFERENCE / UNKNOWN

- **FACT**: `ARCH=quartz`, `ASIC=asic/a0`, CPU `cortex-r4` Thumb, `NETSTACK=lwipv6`, `MRVL_FILTER_ENABLED=1`, `ENABLE_SECOND_FILTER_STAGE=1`, `WITH_BSD_SOCKETS=1`, `IPV6_SUPPORT=1`, `IGMP_SUPPORT=1`, `MAC_FILTERING=0`, `ENABLE_DEBUG=1`, `HAVE_UART=1`, `HAVE_CMD` comment (off); proxy: SNMP+LLMNR+NBNS+wake-service+simple-mdns **on**, bonjour-mdns+openslp **off**; heap 23K/3K, stack 1600/2048; toolchain `s800-r4-`; `LDLIBS += lib/libpmu_r4.a`; target `mvri.bin`.
- **FACT**: các macro proxy trong `Application/Makefile-cfg` khớp 1:1 với `#ifdef` đã thấy ở T5.3/T5.4/T5.6.
- **INFERENCE**: `BUILD_r4` set bởi toolchain/`Makefile-os` (T8.1 dùng nó); `FLEX_quartz` **không** set ⇒ mọi `#ifdef FLEX_quartz` (T8.1 boot-sync `DDR_CONT_BOOT`) không build cho S800.
- **INFERENCE**: `HAVE_CMD` off ⇒ `app_cmdproc.c` (T7.6/T11.3), console gpio/int/dbg **không link** vào `mvri.bin` production. `ApplicationMrvl/Test/*` phần lớn không build (trừ file được include trực tiếp).
- **INFERENCE**: `MODE` value chưa thấy (`release`? `debug`?) — `-DMODE_<MODE>` có nhưng giá trị không trong file đã đọc.
- **UNKNOWN**: `FIRST_RX_PFU`, `HAVE_GBE_PME_INT`, `USE_IDLE_TASK`, `configUSE_IDLE_HOOK`, `TX_ENABLE_IRQ_NESTING`, `KEEP_MC_P_ON`, `DDR_CLK` — chưa grep hết Makefile-lib-cfg (295+ dòng) và FreeRTOSConfig.h.
- **UNKNOWN**: `ARMVLOG` / `OC_CONVERT_VHX` (công cụ hậu xử lý bin — có vẻ ARM fromelf / objcopy wrapper). `RELEASE_BUILD_VERSIONSTRING` nội dung.
- **UNKNOWN**: board `s800es` vs `s800emu` khác nhau macro `-D` gì (board-specific config chưa đọc — có thể `misc/` hoặc env `BOARD`).

## Tóm tắt (theo format skill)

**Build system:** `build_lppp.sh <board>` → `make CROSS_COMPILE=s800-r4-` → recursive Makefile theo submodule (auto-discover bằng `*/Makefile`), ra `mvri.bin` (+`.asm`/`.vhx`/`.h`). Cấu hình toàn cục ở `Makefile-cfg`/`Makefile-lib-cfg`: ARCH=quartz, ASIC asic/a0, Cortex-R4 Thumb, little-endian, NETSTACK=lwipv6 (IPv6+IGMP on, MAC-filtering off), SysFilter + STAGE_2 + BSD sockets on, debug + UART on nhưng **console `HAVE_CMD` off** (ApplicationMrvl/Test không link), heap 23K/3K. `Application/Makefile-cfg` bật đúng 5 proxy (SNMP/LLMNR/NBNS/wake-service/simple-mdns) và tắt bonjour-mdns + openslp — khớp mọi `#ifdef` đã trace. Link thêm binary `lib/libpmu_r4.a` (PMU primitives không có source). Include path tự sinh từ `wildcard` mọi `Application*/`, `ApplicationKM/`, `Sys/*/` header.

**File:line đã tham chiếu:**
