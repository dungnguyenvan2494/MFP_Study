# T5.6 — `Application/thread/app_thread.c`: `ApiAppInit`, `ApiAppMainLoop`, bảng `APP_EVENT_*`, các `AppThread_Handle*`

Nguồn: `lppp_s800/Application/thread/app_thread.c` (1413 dòng),

`lppp_s800/Sys/system/sys_system_thread.c:300-360` (bên phát sự kiện HELLO/GOODBYE/WAKE).

## 1. Bảng `APP_EVENT_*` (`base_api.h:77-85`)

| bit | tên | ai phát | handler trong MainLoop |
|-----|-----|---------|------------------------|
| `0x01` | `APP_EVENT_RECEIVE_PM_PACKET` | `SysFilter_PutPmPkt` (filter có cờ `FOR_APP_LAYER`) → `PmPktQ` | `AppThread_HandlePatternMatchedPacket` |
| `0x02` | `APP_EVENT_CHANGED_NETWORK_CREDENTIALS` | Sys (đổi IP/MAC) | `AppThread_HandleNetworkCredentials` (chỉ log) |
| `0x04` | `APP_EVENT_RECEIVE_MESSAGE_FROM_SYSTEM` | HCI FIFO command channel (Linux gửi `MSG_CMD_*`) | `AppHostcmd_HandleMessageFromSystem` (T6) |
| `0x08` | `APP_EVENT_DRIVER_HELLO` | `SysSystem_NotifyDriverSentHello` ← `SYS_EVENT_DRIVER_HELLO` | `AppThread_HandleDriverHello` |
| `0x10` | `APP_EVENT_DRIVER_GOODBYE` | `SysSystem_NotifyDriverSentGoodbye` ← `SYS_EVENT_DRIVER_GOODBYE` | `AppThread_HandleDriverGoodBye` |
| `0x20` | `APP_EVENT_LINK_DOWN` | Sys (PHY link) | `AppThread_HandleLinkDown` (chỉ log) |
| `0x80` | `APP_EVENT_LINK_UP` | Sys (PHY link) | `AppThread_HandleLinkUp` (chỉ log) |
| `0x100` | `APP_EVENT_SELF_EVENT` | `ApiSysSetEvent_self_event()` (proxy tự đánh thức vòng lặp) | `AppThread_Handle_self_event` |

**Ngữ nghĩa HELLO/GOODBYE** (theo góc nhìn LPPP):
- **`DRIVER_HELLO`** = Linux driver vừa lên / host thức → LPPP **lùi lại**: `ApiSysWakeOnLinkchangeDisable()`, `SystemIsSuspended = SYS_FALSE`. (`RedirectTraffic` được bật ở tầng Sys → mọi gói forward thẳng lên Linux.)
- **`DRIVER_GOODBYE`** = Linux driver rút / host sắp ngủ → LPPP **tiếp quản**: join lại các nhóm multicast, `SystemIsSuspended = SYS_TRUE`, bật wake-on-linkchange (trễ 4s). Tầng Sys trước đó đã `SysLan_setup_gigabit_core()` (re-init GMAC — T5.1) và reset wake-reason.

## 2. `ApiAppInit()` (`app_thread.c:424-476`) — gọi 1 lần từ `SysApi_InitApplModules`

Trình tự:
1. `ApiSysDbgConfigFlags(RESERVED|MAIN|HOSTCMD, ALL)` — bật log 3 module (Linux có thể đổi qua `MSG_CMD_SYSTEM_SET_DEBUG_MASK`).
2. `ApiSysSetAppVersion("AppLayer V1.00")`.
3. `ApiSysWakeOnLinkchangeDisable()` — mặc định TẮT.
4. `own_mcip_heap.count = 0; own_mcip6_heap.count = 0` — danh sách nhóm multicast rỗng (Linux nạp sau qua `MSG_CMD_*`).
5. `#ifdef FILTERS_DEFINED_IN_THIS_MODULE` (bật, T5.4) → **`AppInitSoftwareFilter()`** — đăng ký 8 callback FFL + nạp bảng `filter_stage_1[]` / `filter_stage_2[]`.
6. `#ifdef IPV4_ADDRESS_ENABLED` (BẬT) → `ApiSysNetworkIPv4AddressSet(0xC0A80101, 0xFFFFFF00)` = **192.168.1.1/24 mặc định** (giá trị test; Linux ghi đè IP thật trước khi ngủ). Nhánh `IPV6_ADDRESS_ENABLED`, `IGMP_SAMPLE_GROUPS`, `SNMP_PROXY_SIMPLE_TEST` đều **tắt**.
7. `ApiSysPeriodicTimer(periodic_callback, 1000)` — timer 0, chu kỳ 1000×10ms = **10 s**.
8. `ApiSysPeriodicTimer1(periodic_callback2, 6000)` — timer 1, chu kỳ **60 s**.
9. `return SYS_OK`.

`periodic_callback` / `periodic_callback2` (`:730-737`): **rỗng** (chỉ thân trống / `{}`). ⇒ 2 timer chu kỳ hiện không làm gì (khung để mở rộng).

## 3. `ApiAppMainLoop()` (`app_thread.c:481-503`) — gọi lặp vô hạn từ task `AppMvl`

```c
if (ApiSysGetEventsBLock(&Events) == SYS_OK) {     // BLOCK cho tới khi có event
    if (Events & APP_EVENT_RECEIVE_PM_PACKET)            AppThread_HandlePatternMatchedPacket();
    if (Events & APP_EVENT_RECEIVE_MESSAGE_FROM_SYSTEM)  AppHostcmd_HandleMessageFromSystem();
    if (Events & APP_EVENT_CHANGED_NETWORK_CREDENTIALS)  AppThread_HandleNetworkCredentials();
    if (Events & APP_EVENT_DRIVER_GOODBYE)               AppThread_HandleDriverGoodBye();
    if (Events & APP_EVENT_DRIVER_HELLO)                 AppThread_HandleDriverHello();
    if (Events & APP_EVENT_LINK_DOWN)                    AppThread_HandleLinkDown();
    if (Events & APP_EVENT_LINK_UP)                      AppThread_HandleLinkUp();
    if (Events & APP_EVENT_SELF_EVENT)                   AppThread_Handle_self_event();
}
return SYS_OK;
```
- Dùng bản **BLock** (`ApiSysGetEventsBLock`) → task ngủ khi rảnh, không polling.
- Thứ tự check cố định; nếu nhiều bit set cùng lúc, xử lý tuần tự trong 1 vòng. Đáng chú ý: **GOODBYE xử lý trước HELLO** (nếu cả hai đến trong cùng gói event).

## 4. Chi tiết các `AppThread_Handle*`

### 4.1 `AppThread_HandlePatternMatchedPacket` (`:548-568`)
- `ApiSysNetworkPatternMatchedPacketGet(&pPacket, &Length, &PatternId, &Protocol)` — lấy gói từ `PmPktQ` (do filter `FOR_APP_LAYER` bỏ vào).
- Chỉ xử lý `PatternId == ID_FILTER_STAGE2_HOST_COMMANDS && Protocol == UDP` → `AppHostcmd_via_lan(pPacket, Length)` (kênh lệnh qua LAN, port 2008 — dùng để verify, filter này mặc định DISABLED).
- `ApiSysMemFree(pPacket)` — luôn giải phóng.

### 4.2 `AppThread_HandleNetworkCredentials` / `HandleLinkDown` / `HandleLinkUp` — chỉ `APP_DBG_MSG`, không hành động.

### 4.3 `AppThread_HandleDriverGoodBye` (`:590-611`) — **host chuẩn bị ngủ, LPPP tiếp quản**
1. `AppThread_mcip_handler(&own_mcip_heap, SYS_TRUE)` + `AppThread_mcip6_handler(&own_mcip6_heap, SYS_TRUE)` — **join lại** mọi nhóm multicast IPv4/IPv6 mà Linux đã đăng ký.
2. `SystemIsSuspended = SYS_TRUE`.
3. `check_heap_sizes(1, suspend_count)` — in dung lượng heap system/app còn trống (debug rò rỉ). `suspend_count++`.
4. `#ifdef CHECK_FILTER` → `check_filter(0)` (mặc định tắt).
5. Nếu `ApiSysWakeOnLinkchangeIsEnabled()` → `ApiSysWakeOnLinkchangeEnable_delayed(4)` — bật lại wake-on-linkchange sau 4 s (comment nói "6 giây"; tham số = 4).

### 4.4 `AppThread_HandleDriverHello` (`:613-627`) — **host vừa thức, LPPP lùi lại**
1. (bị comment) không leave nhóm multicast.
2. `ApiSysWakeOnLinkchangeDisable()`.
3. `SystemIsSuspended = SYS_FALSE`.
4. `check_heap_sizes(0, suspend_count)`.

### 4.5 `AppThread_Handle_self_event` (`:642-654`)
- `ApiSysGetTimeOfDay(&tv)`.
- `ApiSysPeriodicTimer(periodic_callback, 500)` — **đặt lại** timer 0 xuống chu kỳ 500×10ms = **5 s** (từ 10 s ban đầu). Cơ chế: proxy mDNS/SLP gọi `ApiSysSetEvent_self_event()` sau khi nhét dữ liệu vào socket → vòng lặp App thức dậy, rút ngắn chu kỳ timer để xử lý sớm. Biến `slp_receive` được `filter_function_mdns_proxy` bật khi thấy SLP.

## 5. `filter_function_magic_packet` (callback FFL #0, STAGE_1) — WoL software

**FACT** (`:1097-1156`). Bổ trợ cho WoL phần cứng (T5.2 tier A):
- yêu cầu `Length >= 6*17 = 102`.
- quét cửa sổ trượt tìm **6 byte `0xFF` liên tiếp** (sync stream).
- sau sync: 16 lần lặp, mỗi lần 6 byte phải `is_own_mac_address()` → nếu đủ 16 lần khớp MAC của mình ⇒ `rc = SYS_TRUE`.
- Đo `duration_us` (profiling, giữ `max_duration`).
- Filter `ID_FILTER_STAGE1_MAGIC_PACKET` có ActionFlags `DISCARD|FORWARD|WAKE_SYSTEM` → khớp ⇒ forward gói + đánh thức host.

## 6. `filter_function_mdns_proxy` (callback FFL #7, STAGE_2)

Chỉ với `FilterID == ID_FILTER_STAGE2_MDNS_PROXY`:
- `dst_port == 5353`:
  - `#ifdef MDNS_PROXY` (bonjour cũ — *"not used anymore"*) → `ApiSysSetEvent_self_event(); return SYS_TRUE`.
  - `#ifdef SIMPLE_MDNS_PROXY` → `return simple_mdns_proxy_process_request(...)` — xem T5.3.
- `dst_port == 427` `#ifdef SLP_PROXY` (openslp cũ — *"not used anymore"*) → `slp_receive = true; ApiSysSetEvent_self_event(); return SYS_TRUE`.
- ActionFlags của filter mDNS = `NONE` → khớp xong "kết thúc stage, nhường network stack" (proxy socket-based tự đọc từ lwIP).

## 8. FACT / INFERENCE / UNKNOWN

- **FACT**: giá trị bit `APP_EVENT_*`, thân `ApiAppInit`/`ApiAppMainLoop`/tất cả `AppThread_Handle*`, `periodic_callback` rỗng, IPv4 default `192.168.1.1/24`, 2 timer 10s/60s, self_event rút timer về 5s, magic-packet 6×0xFF + 16×MAC.
- **FACT**: HELLO/GOODBYE phát từ `sys_system_thread.c` (`SysSystem_NotifyDriverSentHello/Goodbye`); GOODBYE kèm `SysLan_setup_gigabit_core()` + reset wake-reason ở tầng Sys.
- **INFERENCE**: `AppMvl` là task chạy `ApiAppMainLoop` — suy từ T1.5 (task `AppMvl` prio 1) + việc `ApiAppInit`/`MainLoop` là entry chuẩn của App layer Marvell. Chưa mở file tạo task để xác nhận tên chính xác gọi `ApiAppMainLoop`.
- **INFERENCE**: `MDNS_PROXY`/`SLP_PROXY` (bonjour/openslp cũ) không build, `SIMPLE_MDNS_PROXY` build — suy từ comment "not used anymore" + T5.3 đã xác nhận simple_mdns. Chưa xem `.config`/Makefile.
- **UNKNOWN**: `PmPktQ` độ sâu, cơ chế `ApiSysGetEventsBLock` (event group FreeRTOS nào) — để dành khi đọc `sys_system`/`sys_thread`.
- **UNKNOWN**: ai phát `APP_EVENT_LINK_UP/DOWN`, `APP_EVENT_CHANGED_NETWORK_CREDENTIALS` (chưa grep bên phát; handler rỗng nên ít quan trọng).
- **UNKNOWN**: `get_first_global_address()` (khai báo cục bộ trong `appSendUdpPacket`, định nghĩa ở module khác).

## Tóm tắt (theo format skill)

**File này để làm gì:**
`app_thread.c` là "bộ não" của net-proxy Marvell: `ApiAppInit` dựng bộ lọc SysFilter (8 callback + bảng mặc định) và đặt IP test + 2 timer; `ApiAppMainLoop` là vòng lặp event-driven của task `AppMvl`, block chờ 8 loại `APP_EVENT_*` rồi phân nhánh. Hai sự kiện quan trọng nhất là `DRIVER_GOODBYE` (host ngủ → LPPP join lại multicast, `SystemIsSuspended=TRUE`, bật wake-on-linkchange) và `DRIVER_HELLO` (host thức → LPPP lùi lại). File cũng chứa toàn bộ 8 callback filter (magic-packet, ARP, ICMPv6-NS, catch-unknown, ip-multicast, snmp/llmnr/nbns, mdns) và các tiện ích `appSendUdpPacket` / `save_stage1_data` / `mcip_handler` mà các proxy con dựa vào.

**Call flow:**
```
SysApi_InitApplModules
└─ ApiAppInit()
   ├─ AppInitSoftwareFilter()  → 8× ApiSysSoftwarePatternSetCallBackFunction
   │                            + filter_stage_1[]/filter_stage_2[] define+enable
   ├─ ApiSysNetworkIPv4AddressSet(192.168.1.1/24)   [test default]
   └─ ApiSysPeriodicTimer(periodic_callback,10s) + PeriodicTimer1(...,60s)   [cả 2 rỗng]

task AppMvl: while(1) ApiAppMainLoop()
└─ ApiSysGetEventsBLock(&Events)   [ngủ tới khi có event]
   ├─ PM_PACKET      → AppThread_HandlePatternMatchedPacket → (nếu HOST_COMMANDS) AppHostcmd_via_lan
   ├─ MESSAGE_FROM_SYSTEM → AppHostcmd_HandleMessageFromSystem   [T6: MSG_CMD_* từ Linux]
   ├─ DRIVER_GOODBYE → mcip_handler(join) ×2 ; SystemIsSuspended=TRUE ; WakeOnLinkchange_delayed(4)
   ├─ DRIVER_HELLO   → WakeOnLinkchangeDisable ; SystemIsSuspended=FALSE
   ├─ LINK_UP/DOWN/CREDENTIALS → log
   └─ SELF_EVENT     → PeriodicTimer(periodic_callback, 5s)   [proxy rút ngắn để xử lý socket sớm]

bên phát (sys_system_thread.c:329/341):
  SYS_EVENT_DRIVER_HELLO   → HalApiEth_disable_irqs + SysSystem_NotifyDriverSentHello  → APP_EVENT_DRIVER_HELLO
  SYS_EVENT_DRIVER_GOODBYE → SysLan_setup_gigabit_core + SysSystem_NotifyDriverSentGoodbye → APP_EVENT_DRIVER_GOODBYE
```

**File:line đã tham chiếu:**
- `Application/thread/app_thread.c`:424-476 (`ApiAppInit`), :481-503 (`ApiAppMainLoop`), :511-545 (`AppThreadSendResponseToHost_via_lan`), :548-568 (`HandlePatternMatchedPacket`), :570-573 (`HandleNetworkCredentials`), :590-611 (`HandleDriverGoodBye`), :613-627 (`HandleDriverHello`), :629-639 (`HandleLinkDown/Up`), :642-654 (`Handle_self_event`), :730-737 (`periodic_callback*` rỗng), :1097-1156 (`filter_function_magic_packet`), :1056-1094 (`filter_function_mdns_proxy`), :1219-1261 (`mcip_handler`/`mcip6_handler`), :1263-1343 (`appSendUdpPacket`)
- `Sys/sdk/base_api.h`:77-85 (bit `APP_EVENT_*`)
- `Sys/system/sys_system_thread.c`:300-360 (phát HELLO/GOODBYE/WAKE_SYSTEM/CAN_WAKE, gọi `power_cpu`)

Gợi ý: tiếp theo `kernel-arch-diagram` cho vòng đời "host awake ↔ host asleep" (DRIVER_HELLO/GOODBYE ↔ RedirectTraffic ↔ SysFilter).
