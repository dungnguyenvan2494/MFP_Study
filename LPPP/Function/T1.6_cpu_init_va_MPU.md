## 1 · `cpu_init()` (`cortex_r4.c:45-70`) — 3 việc

```c
void cpu_init(void) {
    __asm volatile (
      // ① cho phép đọc cycle counter ở user-mode
      "mrc p15,0,r0,c9,c14,0;  mov r0,#1;  mcr p15,0,r0,c9,c14,0;"
      // ② bật Performance Monitor Control (c9,c12,0 bit0)
      "mrc p15,0,r0,c9,c12,0;  orr r0,r0,#1;  mcr p15,0,r0,c9,c12,0;"
      // ③ bật Cycle Counter (c9,c12,1 bit31 = PMCNTENSET.C)
      "mov r0,#0x80000000;  mcr p15,0,r0,c9,c12,1;"
      :::"r0");

    cpu_initialize_mpu(hwGetRamSize() - hwGetUncachedRamSize());   // ④ §2
    cpu_enable_dcache();                                           // ⑤
}
```

**Cycle counter (CCNT, `c9,c13,0`)** là nền cho: `cpu_get_ccount()`, `cpu_spin_delay()`
(busy-wait tính theo `hwGetProcSpeed()`), FreeRTOS tick timestamp, đo hiệu năng SCPI
(`xTaskGetTickCount`). Bật ở đây, một lần, không bao giờ tắt.

`cpu_spin_delay(us)` (`cortex_r4.c:96`): vòng lặp 1 giây/lượt để mở rộng dải
("@200mhz max WAS 21s, Now 71 minutes"), mỗi lượt so `cpu_get_ccount()` với
`us × hwGetProcSpeed()`. ⇒ **nếu `hwSetProcSpeed` ghi sai số → mọi `udelay`/`cpu_spin_delay` lệch**.

## 2 · `cpu_initialize_mpu(nonCache_address)` (`build_mpu.c:74-120`)

```c
void cpu_initialize_mpu(uint32_t nonCache_address) {
    cpu_disable_mpu();                                            // ① dọn sạch trước
    mpu_region_platform_get_config(&platform_config, nonCache_address);  // ② lấy bảng
    ASSERT(RC_OK == e_res); ASSERT(platform_config);              //   ← ASSERT() RỖNG
    for (i = 0; i < platform_config->number_of_regions; ++i)      // ③ nạp từng vùng
        setMpuRegion(list[i].region, list[i].address, list[i].size,
                     list[i].subregionMask, list[i].type);
    __asm("mrc p15,0,r0,c1,c0,0; orr r0,r0,#1; DSB; mcr p15,0,r0,c1,c0,0; ISB");  // ④ bật MPU
    __asm(" ... ORR R1,R1,#0x1<<12; MCR c7,c5,0; MCR c1,c0,0; ISB");              // ⑤ bật lại I-cache
}
```

### ① `cpu_disable_mpu()` (`build_mpu.c:36-70`)
`cpu_disable_dcache()` → `cpu_dcache_writeback_all()` → clear SCTLR bit12 (I-cache) → ISB
→ `cpu_icache_invalidate_all()` → clear SCTLR bit0 (MPU) → DSB/ISB.
Bắt buộc dọn cache **trước** khi đổi MPU, nếu không dòng cache "mồ côi" với thuộc tính cũ sẽ writeback sai.

### ② `mpu_region_platform_get_config()` (`cortex_r4_mpu_config.c:88-115`)
```c
error_type_t mpu_region_platform_get_config(const mpu_region_platform_config_t **cfg,
                                            uint32_t nonCache_address) {
    ASSERT(NULL != platform_config);
    // ── KHỐI TÍNH pow2 ĐỘNG (dùng nonCache_address) ĐÃ BỊ COMMENT HẾT ──
    // for (pow2 = 31; ...) { if (ram_size & (1<<pow2)) break; }
    // mpu_plat_config.list_of_regions[1].size = pow2 - 1;
    *cfg = &mpu_plat_config;   // ← trả bảng TĨNH, KHÔNG dùng nonCache_address
    return RC_OK;
}
```
⇒ **`nonCache_address` là tham số chết.** Bảng MPU hoàn toàn tĩnh từ `region_bank_list[]`.

### `setMpuRegion()` (`build_mpu.c:15-33`) — mã hoá thanh ghi
```c
void setMpuRegion(uint32_t region, uint32_t address, uint32_t size,
                  uint32_t subregionMask, uint32_t type) {
    tmp_size = (((size << 1) | subregionMask) | 0x1);
    __asm(
      "mcr p15,0,%0,c6,c2,0;"   // MPU Region Number Register  ← region
      "mcr p15,0,%1,c6,c1,0;"   // MPU Region Base Address Reg ← address
      "mcr p15,0,%2,c6,c1,4;"   // MPU Region Access Control   ← type
      "mcr p15,0,%3,c6,c1,2;"   // MPU Region Size & Enable    ← tmp_size
      :: "r"(region), "r"(address), "r"(type), "r"(tmp_size) : ...);
}
```

**Size & Enable Register (`c6,c1,2`) format:**
```
 bit0      = enable
 bits[5:1] = region size N  → kích thước = 2^(N+1)
 bits[15:8]= subregion disable (1 = tắt subregion đó, 8 subregion / vùng)
```
`tmp_size = (size<<1) | subregionMask | 1` → `size` (N, 5-bit) vào bits[5:1], `subregionMask`
vào bits[15:8] (nên trong config nó đã ở dạng `0xe000`, không phải `0xe0`).

## 3 · Bảng 5 vùng — mã hoá thật (`cortex_r4_mpu_config.c:33-72` + `_config.h:24-61`)

`MPUSIZE_*` = giá trị N: `4GB=0x1F, 1GB=0x1D, 256KB=0x11, 128KB=0x10`.
`MPUTYPE_*` (nạp vào `c6,c1,4`): `NOCACHE=0x308, DEVICE=0x301, WBWACACHE=0x329, ROCACHE=0x629`.

| # | address | .size | .subregionMask | .type | `tmp_size` (c6,c1,2) | `type` (c6,c1,4) |
|---|---|---|---|---|---|---|
| 0 | `0x00000000` | `MPUSIZE_4GB` (0x1F) | `0x0000` | `NOCACHE` (0x308) | `(0x1F<<1)\|0\|1 = 0x3F` | `0x308` |
| 1 | `0xC0000000` | `MPUSIZE_1GB` (0x1D) | `0x0000` | `DEVICE` (0x301) | `0x3B` | `0x301` |
| 2 | `&__start_ram__` = `0xE8200000` | `MPUSIZE_256KB` (0x11) | `0x0000` | `WBWACACHE` (0x329) | `0x23` | `0x329` |
| 3 | `&__rom_start__` = `0xF8000000` | `MPUSIZE_128MB` (0x1A) | `0` | `ROCACHE` (0x629) | `0x35` | `0x629` |
| 4 | `&__nocache_start__` = `0xE8200000` | `MPUSIZE_128KB` (0x10) | `0xe000` | `NOCACHE` (0x308) | `(0x10<<1)\|0xe000\|1 = 0xe021` | `0x308` |

**Giải mã `type`:**
- `NOCACHE 0x308` = XN(12)=0, AP[10:8]=0b011 (RW/RW), TEX[5:3]=0b001, S(2)=0, CB[1:0]=0b00 → *Outer/Inner Non-cacheable*
- `DEVICE 0x301` = AP=0b011, TEX=0b000, CB=0b01 → *Shareable Device*
- `WBWACACHE 0x329` = AP=0b011, TEX=0b001, C=1, B=1 → *WB, write-allocate*
- `ROCACHE 0x629` = AP[10:8]=**0b110** (RO/RO — privileged & user read-only), TEX=0b001, CB=0b01 → *RO cached* (chống ghi nhầm vào ảnh firmware XIP)

**Giải mã vùng 4 (`0xe021`):**
- bits[5:1] = 0x10 → N=16 → size = 2^17 = **128 KB**
- bits[15:8] = 0xe0 → tắt subregion **5, 6, 7** (mỗi subregion = 128KB/8 = 16KB)
- ⇒ **5 subregion đầu × 16KB = 80 KB** hoạt động từ `0xE8200000` → `0xE8214000`

**Quy tắc chồng lấn R4:** vùng số hiệu CAO thắng. Nên tại `0xE8200000`–`0xE8213FFF`:
vùng 4 (NOCACHE) đè vùng 2 (WBWA cache) đè vùng 1 (DEVICE) đè vùng 0 (NOCACHE nền).

## 4 · `hwGetRamSize` / `hwGetUncachedRamSize` (`hwconfig.c:207-218`)

```c
uint32_t hwGetRamSize(void)          { return hw_config_table.platform_mem_size; }  // = DUNG LƯỢNG DDR (AP806)
uint32_t hwGetUncachedRamSize(void)  { return 0x0; }   /// revisit when tlb can handle subblocks
```

⇒ `cpu_initialize_mpu(hwGetRamSize() - hwGetUncachedRamSize())`
  = `cpu_initialize_mpu(platform_mem_size - 0)`
  = `cpu_initialize_mpu(<DDR size>)`
  — nhưng **tham số này bị `mpu_region_platform_get_config` bỏ qua** (§2).

Cả hàm `cpu_initialize_mpu` có comment cũ: *"Enables caching on the address 0 to memory_size.
The rest is not cached"* — **mâu thuẫn** với bảng tĩnh hiện tại (vùng 0 = DDR = **NOCACHE**).
Comment là di sản thiết kế "DDR cached tới memory_size", đã bị thay bằng bảng tĩnh 5 vùng.

`hwAddressIsCached(addr)` = `addr < (ram_start + ram_size - 0)` — với `uncached = 0` thì hàm này
**luôn trả true cho mọi địa chỉ trong DDR** → không đáng tin, không code sản xuất nào dựa vào nó.

## 5 · Nội dung vùng 80KB NOCACHE (`memory_sections.ld:58-95`)

```ld
.data.nocache __start_ram__ (NOLOAD) : {      /* anchor tuyệt đối để thoả căn chỉnh MPU */
    __nocache_start__ = .;                    /* = 0xE8200000 */

    __qhead_start__ = .;                      /* khớp usbd_qhead_lcm trong Linux DTS */
    *(.usbd2_qh_sec);                         /*   USB2 device queue heads          */
    __qhead_end__ = __qhead_start__ + 0x0800; /*   2 KB cố định                     */
    . = __qhead_end__;                        /*   ← ld error nếu tràn              */

    __data_fifo_start__ = .;                  /* khớp net-proxy-hci trong Linux DTS */
    *(.fifosec);                              /*   HCI FIFO (IPC Linux driver ↔ R4) */
    __data_fifo_end__ = __data_fifo_start__ + 0x1880;  /* 6.125 KB cố định          */
    . = __data_fifo_end__;

    *(.netbufsec);                            /*   packet descriptor (GMAC DMA)     */
    *(.bufpools);                             /*   buffer pool                      */

    __nocache_data_end__ = .;                 /* dữ liệu thật kết thúc ở đây        */
    __nocache_end__ = __nocache_start__ + (80 * 1024);   /* ← PHẢI KHỚP MPU vùng 4 */
    . = __nocache_end__;                      /* ld error "cannot move location
                                                counter backwards" nếu dữ liệu > 80KB */
}
```

| Offset | Nội dung | Kích thước | Đối tác |
|---|---|---|---|
| `0x00000` | `.usbd2_qh_sec` USB2 qhead | 2 KB | Linux DTS `usbd_qhead_lcm` |
| `0x00800` | `.fifosec` HCI FIFO | 6.125 KB | Linux DTS `net-proxy-hci` (kênh IPC #2) |
| `0x02080`+ | `.netbufsec` + `.bufpools` | phần dư (~72 KB) | DMA của GMAC |
| `0x14000` | `__nocache_end__` (mốc cố định) | — | MPU vùng 4 (`0xe021` → 80KB) |

**Vì sao 80KB đầu LCM phải NOCACHE:**
1. `.usbd2_qh_sec` + `.fifosec` — **Linux (A72) truy cập trực tiếp** qua LCM. Cache của R4 không
   coherent với A72 → phải NOCACHE để hai bên thấy cùng dữ liệu.
2. `.netbufsec` + `.bufpools` — **GMAC DMA đọc/ghi thẳng bộ nhớ**. Nếu cached, phải
   invalidate/clean thủ công mỗi gói (như CDMA). Với lưu lượng mạng liên tục thì tắt cache hẳn
   đơn giản và an toàn hơn.

**Mẹo linker bắt lỗi biên dịch:** `. = __<x>_end__;` sau mỗi block đẩy location counter tới mốc
cố định. Nếu dữ liệu vượt → `ld: cannot move location counter backwards`. Áp dụng cho
`__qhead_end__` (2KB), `__data_fifo_end__` (6.1KB), `__nocache_end__` (80KB). Đây là cách duy
nhất bắt được "hợp đồng địa chỉ" giữa firmware và Linux DTS — vì DTS chỉ khớp bằng comment.

## 6 · Hai lần MPU — asm sớm vs C (nối T1.3)

| | asm sớm (`hal_init_gnu.asm` + `hal_mpu_table_gnu.asm`) | C (`cpu_initialize_mpu`) |
|---|---|---|
| Số vùng | 4 | 5 |
| DDR (`0x0`) | **WBWA cache** | **NOCACHE** |
| QSPI (`0xF8`) | **WBnWA cache** | **RO cache** (chống ghi) |
| Vùng 80KB NOCACHE | ❌ không có | ✅ vùng 4 |
| Khi có hiệu lực | reset → `cpu_init()` | `cpu_init()` → mãi mãi |
| ⚠ `.equiv MPU_SETUP_AND_ENABLE,0` | `.ifdef` xét *tồn tại* → **likely CHẠY** | luôn chạy |

Bản C **ghi đè hoàn toàn** (mỗi vùng ghi lại cả 4 thanh ghi c6). Bản asm sớm chỉ cần cache
hoạt động khi XIP + copy `.data` trong `hal_main_initialize_sections()`.

## 7 · Tóm tắt (theo format skill)

**1. Tồn tại để làm gì:** `cpu_init()` bật cycle counter (CCNT — nền của mọi `cpu_spin_delay`
và tick) rồi gọi `cpu_initialize_mpu()` nạp bảng MPU 5 vùng **tĩnh** (`cortex_r4_mpu_config.c`):
nền NOCACHE 4GB, DEVICE 1GB `0xC0000000`, LCM WBWA-cache 256KB, QSPI RO-cache 128MB, và **80KB
đầu LCM NOCACHE** (vùng 4, mã `0xe021` = 128KB region tắt 3 subregion cuối) cho DMA GMAC + cửa
sổ chia sẻ với Linux (USB qhead + HCI FIFO).

**2. Call flow:**
```
main() [hal_main.c:691]
└─ cpu_init() [cortex_r4.c:45]
   ├─ enable CCNT (c9,c14 / c9,c12,0 / c9,c12,1)
   ├─ cpu_initialize_mpu( hwGetRamSize() - hwGetUncachedRamSize()=0 )  [build_mpu.c:74]
   │   ├─ cpu_disable_mpu()             [dcache wb + icache inval + MPU off]
   │   ├─ mpu_region_platform_get_config()  → bảng TĨNH 5 vùng (nonCache_address bị bỏ qua)
   │   ├─ setMpuRegion() ×5             [c6,c2,0 / c6,c1,0 / c6,c1,4 / c6,c1,2]
   │   ├─ SCTLR bit0 = 1               [bật MPU]
   │   └─ SCTLR bit12 = 1 + inval      [bật lại I-cache]
   └─ cpu_enable_dcache()
```

**4. Đã xác nhận / phát hiện:**
- ✅ `hwGetUncachedRamSize()` **trả `0x0`** ("revisit when tlb can handle subblocks") →
  tham số `nonCache_address` của `cpu_initialize_mpu` = DDR size, nhưng **bị bỏ qua hoàn toàn**
  (khối `pow2` động trong `mpu_region_platform_get_config` đã comment). Bảng MPU 100% tĩnh.
- ✅ Vùng 4 mã `0xe021`: 128KB region, tắt subregion 5/6/7 → **80KB** từ `0xE8200000`.
- ✅ DDR (`0x0`) là **NOCACHE** ở bản C (asm sớm là WBWA) — comment "Enables caching 0..memory_size"
  của `cpu_initialize_mpu` là di sản SAI.
- ✅ `hwAddressIsCached()` luôn trả `true` cho DDR (vì `uncached=0`) — không đáng tin.
