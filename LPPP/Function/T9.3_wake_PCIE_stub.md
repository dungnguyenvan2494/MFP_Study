## 1. Toàn bộ nội dung file

```c
int pcie_suspend(void *dev, int flags) {
    pmu_pm_ops_done(flags);
    return 0;
}
int pcie_resume(void *dev, int flags) {
    pmu_pm_ops_done(flags);
    return 0;
}
pmu_pm_ops_t pcie_ops = { .resume = pcie_resume, .suspend = pcie_suspend };

uint32_t wake_pcie_init(void **mem, uint32_t *memsize) {
    SYS_DBG_MSG(..., "%s: register\n", __func__);
    pmu_pm_ops(&pcie_ops, NULL);
    return 0;
}
```

🔴 **Cả hai callback chỉ gọi `pmu_pm_ops_done(flags)` rồi return 0.** Không đụng thanh ghi PCIe, không cấu hình ngắt, không MSI, không LTSSM. `wake_pcie_init` (gọi từ `SysApi_InitApplModules`, `sys_init.c:182`) chỉ đăng ký cặp callback rỗng vào danh sách `pmu_pm_ops`.

## 2. Kết luận: LPPP **KHÔNG** làm wake-on-PCIe cho S800

- Không có "giữ link PCIe sống khi ngủ", không có wake theo MSI/link-event như `wake_USBD` làm với USB2 (T9.2).
- `pcie_ops` chỉ tồn tại để "không chặn" chuỗi `pmu_phase` (mỗi callback phải gọi `pmu_pm_ops_done` để pha tiến tiếp) — placeholder.
- Include `iris.h`, `mci_local.h` nhưng không dùng gì.

### Wake của các thiết bị "PCIe-ish" đi đường khác:
| thiết bị | đường đánh thức | tham chiếu |
|----------|-----------------|-----------|
| Fiery (bộ điều khiển in ngoài) | **GPIO** `WAKE_FIERY` pin 52 (BANK B[20], `LEVEL_HIGH`) → `WAKEUP_S1` | T7.2 §1.2, `pad_config.c:123` |
| WLAN | **GPIO** `WAKE_WLAN` pin 58 (`LEVEL_LOW`, đổi 2018-11-08) → `WAKEUP_S1`; `HST_WAKE_WL` pin 73 = output (R4→WLAN host-wake) | T7.2 |
| SSD / NVMe | `SSD_DETECT`/`SSD_DETECT2` (pin 245/242) chỉ để phát hiện cắm, không wake | T7.2 |
| USB2 device | `wake_USBD` (T9.2) — cơ chế thật duy nhất |
| Ethernet | WoL magic packet + SysFilter (T5.2, T9.4) |

⇒ Các thiết bị trên bo mạch S800 dùng **GPIO wake** (HW wake domain đánh thức hệ thống, `wake_gpio_info[]` với `LPPP_GPIO_CallbackDummy` — T7.2), không phải logic PCIe trong R4.

## 3. FACT / INFERENCE / UNKNOWN

- **FACT**: `wake_pcie.c` 41 dòng, cả `pcie_suspend`/`pcie_resume` chỉ `pmu_pm_ops_done` + return 0; `wake_pcie_init` chỉ `pmu_pm_ops(&pcie_ops)`; gọi từ `sys_init.c:182`.
- **FACT**: `WAKE_FIERY`/`WAKE_WLAN` là GPIO wake (`LPPP_Gpio.c`, `pad_config.c`).
- **INFERENCE**: wake-on-PCIe từng được dự tính (file tồn tại, include iris/mci) nhưng chưa hiện thực cho S800 — hoặc không cần vì mọi thứ đi GPIO/USB/Ethernet. Chưa thấy version nào của file này có code thật (chỉ 1 bản).
- **UNKNOWN**: S800 có dùng PCIe không (Iris die có PCIe controller theo T0.x, nhưng có thiết bị PCIe endpoint nào trên bo không rõ — có thể Fiery qua PCIe nhưng wake vẫn qua GPIO sideband).
