## 0 · HAI hệ clock riêng biệt

| | **Clock tree THẬT** | **SCPI clock model** |
|---|---|---|
| Ở đâu | `power_up_clk[]` (`power_clock_init.h`) + `pmu_set_clock`/`pmu_set_sspll` (`libpmu_r4.a`) + PLL | `hal_quartz_clks.c` — mảng `clocks[13]` tĩnh |
| Điều khiển phần cứng? | **CÓ** — ghi thanh ghi PMU CLKGEN | **KHÔNG** — chỉ đọc/ghi `cur_value` trong RAM |
| Ai dùng | `pmu_phase(pmu_baseline)`, `LPPP_McChangeFreq`, resume | SCPI `0x0d`–`0x10` → Linux `clk-scpi` |
| Số clock | 76 (`pmu_clocks` enum) | 13 (bịa) |

⚠ **Linux `clk-scpi` thấy một mô hình 13 clock HOÀN TOÀN HƯ CẤU.** Nó có thể "set" `bspi_clk`
= 80MHz rồi đọc lại đúng 80MHz, nhưng phần cứng QSPI thật do `pmu_set_clock(pmu_qspi_clk, ...)`
trong `pmu_baseline` đặt. Stub tồn tại vì giao thức SCPI **bắt buộc** hỗ trợ clock domain và
driver `clk-scpi` cần *thứ gì đó* để bind.

## 1 · Ba PLL + ref (`power_api.h:26-48`, `power_clock_init.h:7`)

```
REFCLK25M  = 25 MHz thạch anh   (REF25M_KHZ = 25000 ; pmu_REFCLK25M = enum 65)
SSPLL_SYS_DEFAULT = 1600 MHz   SYS_PLL   SSC = on_down_2   (SYSPLL_SSC_DEFAULT)
SSPLL_MC_DEFAULT  = 2100 MHz   MC_PLL    SSC = on_down_3   (MCPLL_SSC_DEFAULT)
SSPLL_ND_DEFAULT  = 2400 MHz   ND_PLL    SSC = off
pmu_AVPLL                       — PLL audio
```
`SSPLL_MHZ_1600/2100/2400` — 3 tần số PLL cho phép (`power_api.h:26-28`).
`SYS_BUS_CLOCK_2X = 400`, `SYS_BUS_CLOCK = 200` (= 400/2), `SYS_BUS_CLOCK_D2 = 12` (= 25/2, ghi
sổ lúc `hwConfigInit` trong `main()`), `SYS_BUS_CLOCK_REF25 = 25`.

`pmu_baseline` (T4.1 §2): `pmu_set_sspll(SYS_PLL, D0, 1600)`, `hwSetProcSpeed(200)`,
`pmu_set_sspll(MC_PLL, D0, 2100)`, `pmu_set_sspll(ND_PLL, D0, 2400)`.

## 2 · `power_up_clk[]` — bảng bộ chia (`power_clock_init.h:15-95`)

Mảng **designated-init** index theo `pmu_clocks` enum (76 phần tử). `.clk = 0xFF` = **skip**
(clock cố định-dẫn xuất, hoặc cấu hình ở nơi khác). `.div` tính bằng công thức
`PLL_MHz / target_MHz`, `DIV_UP(x) = x+1`.

### 2.1 · Nhánh SYS_PLL (1600 MHz)

| Clock (enum) | src | `.div` | Target | Ghi chú |
|---|---|---|---|---|
| `pmu_i_clk_yyy_0s` (29) | NO_CHANGE | `1600/400` = 4 | **400 MHz** | "setup early" — gốc của mọi busclk |
| `pmu_busclk_*` (14-28) | (0xFF skip) | FIXED **÷2** của yyy | **200 MHz** | `busclk_lppp` = bus của R4 → `hwSetProcSpeed(200)`; `busclk_pmucpu` gated nếu M4 unused |
| `pmu_qspi_clk` (13) | NO_CHANGE | `1600/50` = 32 | 50 MHz ban đầu | max 266; `pmu_baseline` đổi `.div=8` → **200 MHz** (rev≥A1 & GPIO I[31]==0) |
| `pmu_pibusclk` (42) | NO_CHANGE | `1600/320` = 5 | **320 MHz** | PI bus → FIXED `pibusclk_mcix4`, `pibusclk_gpu_aclk` |
| `pmu_lcdpll_clk` (36) | **SYS_PLL** | `DIV_UP(1600/75)` = 22 | 75 MHz | src tường minh |
| `pmu_sdmmcbaseclk` (37) | NO_CHANGE | `1600/400` = 4 | 400 MHz | |
| `pmu_gpu_core_clk` / `pmu_gpu_clkSh` (38/39) | NO_CHANGE | `1600/533` = 3 | 533 MHz | |

### 2.2 · Nhánh MC_PLL (2100 MHz) — miền Machine Control

| Clock | `.div` | Target | Ghi chú |
|---|---|---|---|
| `pmu_mc_spi_clk_0/1` (33/34) | `DIV_UP(2100/263)` = 8 | 263 MHz | `LPPP_mc_spi_clk_set()` đặt div=8 (T3.5) |
| `pmu_mc_qsclk` (35) | `2100/100` = 21, **gate=running** | 100 MHz | ⚠ `LPPP_McChangeFreq_handler` **đổi runtime** theo yêu cầu M3 (T3.5) |
| `pmu_i_clk_mmm` (68) | `2100/350` = 6, gate=running | 350 MHz | → `traceclk` /1 = 350 MHz |
| `pmu_atg_mciclk` (53) | `DIV_UP(2100/500)` = 5 | 420 MHz | MCI, max 500 |

### 2.3 · Nhánh ND_PLL (2400 MHz) — die-to-die + audio + LVDS ref

| Clock | `.div` | Target | Ghi chú |
|---|---|---|---|
| `pmu_audio_pre_clk` (3) | `2400/600` = 4 | 600 MHz | → `audio_clk` `/40` = 15 MHz |
| `pmu_pidi_c2c_clk` (40) | `2400/600` = 4 | 600 MHz | **die-to-die C2C**; rev A0 → `2400/300` = 8 (`power_set_clock_div`) |
| `pmu_pidi_scan_clk` (41) | `2400/240` = 10 | 240 MHz | |
| `pmu_vby1_tx_refclk_0/1` (66/67) | `2400/133` = 18 | 133 MHz | **LVDS TX ref → print head** (Vx1) |
| `pmu_vby1_rx_refclk_0/1` (30/31) | `DIV_UP(2400/70)` = 35 | 70 MHz | LVDS RX ref |

### 2.4 · Ref/thấp
| Clock | src | `.div` | Target |
|---|---|---|---|
| `pmu_tsenclk` (0) | NO_CHANGE | `25000/500` = 50 | 500 kHz (cảm biến nhiệt) |
| `pmu_clk32k` (5) | NO_CHANGE | `25000/32` = 781 | ~32 kHz |
| `pmu_uartclkgen_0..6` (69-75) | **REFCLK25M** | 1 | 25 MHz ref (chia phân số riêng cho baud) |

### 2.5 · `power_set_clock_div()` (`power.c:1846-1880`) — áp bảng
```c
if (get_quartz_rev() == QUARTZ_REV_A0)
    power_up_clk[pmu_pidi_c2c_clk].div = SSPLL_ND_DEFAULT / 300;   // = 8 (rev A0 chạy nửa tốc độ)
for (i = 0; i < 76; i++) {
    if (power_up_clk[i].clk == 0xFF) continue;                     // skip
    pmu_get_clock(clk, &gate, &div, &src);
    if ((gate && gate != cur_gate) || (div && div != cur_div) || (src && src != cur_src))
        pmu_set_clock(clk, gate, div, src);                        // CHỈ ghi khi khác (0 = NO CHANGE)
}
```
Gọi trong `pmu_baseline` (T4.1 §2), **sau** khi khoá SYS_PLL 1600.

## 3 · Sơ đồ clock tree

```
XTAL 25 MHz ─┬─► SYS_PLL 1600 (SSC on_down_2)
             │     ├─/4→ i_clk_yyy_0s 400 ─┬─/2(FIXED)→ busclk_lppp/cdma/lcm/... 200 ─► R4 bus (hwSetProcSpeed 200)
             │     │                        └─/2→ busclk_pmucpu (gated)
             │     ├─/32→50 (rev≥A1:/8→200) → qspi_clk       ─► QSPI CS0/CS1 XIP
             │     ├─/5→ pibusclk 320 ─FIXED→ pibusclk_mcix4 / gpu_aclk
             │     ├─/22→ lcdpll_clk 75
             │     ├─/4→ sdmmcbaseclk 400
             │     └─/3→ gpu_core_clk / gpu_clkSh 533
             │
             ├─► MC_PLL 2100 (SSC on_down_3)   [Machine Control]
             │     ├─/8→ mc_spi_clk_0/1 263
             │     ├─/21→ mc_qsclk 100  ◄── LPPP_McChangeFreq_handler đổi RUNTIME (M3 yêu cầu)
             │     ├─/6→ i_clk_mmm 350 ─/1→ traceclk 350
             │     └─/5→ atg_mciclk 420 (MCI)
             │
             ├─► ND_PLL 2400 (SSC off)   [die-to-die / audio / LVDS ref]
             │     ├─/4→ audio_pre_clk 600 ─/40→ audio_clk 15
             │     ├─/4→ pidi_c2c_clk 600 (die-to-die; rev A0 /8)

             │     └─/35→ vby1_rx_refclk_0/1 70

             ├─► AVPLL (audio)
             │
             └─ /50→ tsenclk 500k · /781→ clk32k 32k · REFCLK25M→ uartclkgen_0..6
```

## 4 · `hal_quartz_clks.c` — SCPI clock model (STUB, 170 dòng)

```c
typedef struct { uint16_t flags; uint32_t minimum_rate, maximum_rate, cur_value; char clkname[20]; } quartz_clk_entry_t;

quartz_clk_entry_t clocks[] = {
    { .flags=1, .min=.max=.cur=20000,     "tsenclk"       },   // id 0  ⚠ 20kHz (bảng thật = 500kHz!)
    { .flags=1, .min=.max=.cur=20000,     "audio_pre_clk" },   // id 1  ⚠ 20kHz (thật = 600MHz!)
    { .flags=1, .min=.max=.cur=20000,     "audio_clk"     },   // id 2  ⚠ 20kHz (thật = 15MHz!)
    { .flags=1, .min=.max=.cur=32768,     "clk32k"        },   // id 3
    { .flags=1, .min=.max=.cur=25000000,  "uart0"         },   // id 4..10  uart0..6 = 25MHz
    ... uart1..uart6 ...
    { .flags=3, .min=0, .max=1000000,   .cur=1000000,   "test_clk" },  // id 11  điều chỉnh được
    { .flags=3, .min=0, .max=100000000, .cur=50000000,  "bspi_clk" },  // id 12  điều chỉnh được, cur 50MHz
};

uint16_t hal_get_num_clks(id)   { return 13; }
int16_t  hal_get_clk_flags(id)  { if (id > 13) return -1;  return clocks[id].flags; }   // ⚠ off-by-one: nên >= 13
uint32_t hal_get_minimum(id)    { return clocks[id].minimum_rate; }
uint32_t hal_get_maximum(id)    { return clocks[id].maximum_rate; }
char*    hal_get_clkname(id)    { return clocks[id].clkname; }
uint32_t hal_get_clk_freq(id)   { return clocks[id].cur_value; }        // ← KHÔNG đọc phần cứng
void     hal_set_current(id, r) { clocks[id].cur_value = r; }           // ← KHÔNG ghi phần cứng
```

`flags`: **1** = tần số cố định (`min == max`), **3** = điều chỉnh được (có dải).
⚠ `hal_get_clk_flags` kiểm biên `id > 13` — nên là `id >= 13` (13 phần tử, index hợp lệ 0..12).
⚠ Giá trị `tsenclk/audio_*` trong stub (**20000 Hz**) mâu thuẫn với bảng thật (500kHz/600MHz/15MHz)
— chứng tỏ stub được điền tuỳ tiện, không ai đồng bộ.

### SCPI `0x0d`–`0x10` (`app_scpi.c`, `AppMhuTest.md §Phần C`)

| SCPI | Handler | Gọi |
|---|---|---|
| `0x0d` Get clocks capability | trả `hal_get_num_clks(clock_id)` = **13** | — |
| `0x0e` Get clock info | điền `{clock_id, flags=hal_get_clk_flags, min, max}` + `strcpy(hal_get_clkname)` nối sau struct; `payload_size = strlen + sizeof(struct)` | ⚠ nếu `flags == -1` → `return true` **bỏ qua cache writeback** (bug F.2 trong `AppMhuTest.md`) |
| `0x0f` Set clock rate | `hal_set_current(clock_id, rate)` — chỉ cập nhật `cur_value`; `send_response = false` | rate lấy từ `payload[1]` |
| `0x10` Get clock rate | `header_dest->payload = hal_get_clk_freq(clock_id)` | |

⇒ Linux `clk-scpi` (`drivers/clk/clk-scpi.c`, T2.5) đăng ký 13 clock từ bảng này. `clk_set_rate`
trên `bspi_clk` → SCPI `0x0f` → `hal_set_current` → chỉ đổi RAM. Phần cứng không nhúc nhích.

## 5 · Tóm tắt (theo format skill)

**1. Tồn tại để làm gì:** Quartz có **3 PLL** — SYS 1600 (bus R4 200 MHz, QSPI, PI bus 320, GPU
533, SDMMC, LCD), MC 2100 (Machine Control: `mc_spi` 263, `mc_qsclk` 100 — đổi runtime, MCI 420),
ND 2400 (die-to-die PIDI C2C 600, audio, LVDS Vx1 TX ref 133 tới print head). Bảng `power_up_clk[]`
(76 entry) chứa `.div = PLL/target`; `power_set_clock_div()` áp trong `pmu_baseline` qua
`pmu_set_clock`. **Riêng biệt hoàn toàn** là `hal_quartz_clks.c` — bảng 13 clock **tĩnh, không
chạm phần cứng**, chỉ để SCPI `0x0d`–`0x10` báo cáo cho Linux `clk-scpi`.

**2. Bảng tra:** §1 (PLL) + §2 (bộ chia) + §3 (sơ đồ) + §4 (SCPI stub).

**3. File đã tham chiếu:**
- `Hal/quartz/asic/build/power_api.h:26-48`
- `Hal/quartz/asic/build/power_clock_init.h` (toàn bộ)
- `Hal/quartz/asic/build/pmu_lib.h:33-112` (`pmu_clocks` enum 76 entry)
- `Hal/quartz/asic/build/power.c:1846-1880` (`power_set_clock_div`)
- `Hal/quartz/clocks/src/hal_quartz_clks.c` (toàn bộ 170 dòng), `include/hal_quartz_clks.h`

**4. Đã xác nhận / phát hiện:**
- 🔴 **`hal_quartz_clks.c` là STUB** — `hal_get_clk_freq`/`hal_set_current` chỉ đọc/ghi `cur_value`
  trong RAM, **không đụng phần cứng**. Linux `clk-scpi` thấy 13 clock hư cấu.
- ✅ 3 PLL: SYS 1600 / MC 2100 / ND 2400 MHz, ref 25 MHz. SSC: SYS `on_down_2`, MC `on_down_3`.
- ✅ Bus R4 = `busclk_lppp` = `i_clk_yyy_0s (400) ÷ 2` = **200 MHz** → `hwSetProcSpeed(200)`.
- ✅ QSPI: 50 MHz ban đầu, `pmu_baseline` đổi `.div=8` → 200 MHz (rev≥A1 & GPIO I[31]==0).
- ✅ `mc_qsclk` div 21 (100 MHz) mặc định — `LPPP_McChangeFreq_handler` **đổi runtime** theo M3 (T3.5).
- ✅ `vby1_tx_refclk` 133 MHz (ND_PLL/18) = ref cho LVDS TX tới print head (nối T3.4).
- ✅ `pidi_c2c_clk` 600 MHz (die-to-die); rev A0 → 300 MHz.
- ✅ `power_set_clock_div` chỉ ghi clock khi giá trị khác (`0 = NO CHANGE`).
- 🟡 `hal_get_clk_flags` off-by-one (`> 13` nên `>= 13`); stub `tsenclk`=20kHz mâu thuẫn bảng thật 500kHz.

**Gợi ý:** `kernel-arch-diagram` để vẽ clock tree 3-PLL này thành Mermaid.
