## 1. Hai đường "in" độc lập

### 1.1 Đường LOG runtime — `*_DBG_MSG` / `SysDebug_Printf` / `ApiSysDebug_Printf`

```
APP_DBG_MSG / APPKM_DBG_MSG / SYS_DBG_MSG(...)          [macro trong từng module]
  → ApiSysDebug_Printf("APP",…)  |  SysDebug_Printf("SYS",…)   [Sys/debug/*]
     → SysApiPrint_Write(prefix, Component, Category, fmt, va_list)   [Sys/system/sys_print.c:61]
        ├─ if (!isLogOut) return RC_OK;                 ← CỔNG DUY NHẤT
        ├─ // if (!(Component & PrintBuf.debug_module)) …  ← 🔴 BỊ COMMENT
        ├─ SysSystem_EnterCritical()
        ├─ dbg_vprintf(fmt, args)                        [Hal/quartz/debug/src/dbg.c:124]
        │    → vfstrfmt(_add_char, NULL, fmt, ap)        [format thủ công, không dùng libc printf]
        │       → _add_char(c) mỗi ký tự
        │          → debug_print("<c>")                  [hal_main.c:232]
        │             → debug_print_w_id(0, str)
        │                → for each char:
        │                     while (!(sys_uarts[0]->UART_LSR & (1<<5)));  // chờ THR empty (bit5 = TDRQ/THRE)
        │                     sys_uarts[0]->union0.UART_THR = c;           // ghi 1 byte
        ├─ dbg_vprintf("\r", args)                       // thêm CR
        └─ SysSystem_ExitCritical()
```

**Đặc điểm:**
- **Blocking, per-char, trong critical section** — mỗi ký tự poll `UART_LSR` bit5. In nhiều = làm chậm hệ thống đáng kể.
- **Cổng duy nhất = `isLogOut`** (biến toàn cục `bool`). `true` → in tất cả.
- Bộ lọc Component/Category (`PrintBuf.debug_module`/`debug_category`, set qua `ApiSysDbgConfigFlags`/`SysApiPrint_ConfigFlags`) **không được kiểm** trên hot path — 2 dòng `if` bị `//`. ⇒ `ApiSysDbgConfigFlags(...)` trong `ApiAppInit` (T5.6) và `SysApi_InitApplModules` **hầu như vô tác dụng** với đường này. (Lọc có thể xảy ra ở tầng macro `*_DBG_MSG` — tuỳ định nghĩa, chưa kiểm hết.)
- `_add_char` → `debug_print` → **KHÔNG dùng `PrintBuf` ring buffer** — `PrintBuf` (`struct fw_printbuffer`: `size_total, read_ptr, size_fifo_only, write_ptr, buffer[FW_PRINTBUFFER_SIZE], debug_module, debug_category`) được `SysPrint_Init()` khởi tạo nhưng đường in này bỏ qua, ghi thẳng UART. (`PrintBuf` là di sản / dùng cho `dbg_outbuf_replay` ở build khác.)
- `dbg_printf` (bản trực tiếp trong `dbg.c`) có `_handle_timestamp()` + `_handle_namestamp()` (in `[TênTask]` hoặc `[ISR/Timer]`) — nhưng `SysApiPrint_Write` gọi `dbg_vprintf` (không stamp).

### 1.2 Đường CONSOLE — `app_cmdproc.c` (ApplicationMrvl/Test)

```
app_cmdproc: nhận ký tự RX → parse dòng lệnh → callback
  in kết quả: HalApiPrint_printsmbus(buf, len)              [hal_print.c:211]
     switch on smbus_or_spi[0]  (giá trị ASCII):
        & 1 → printsmbus()   [chỉ khi USE_SMBUSDEBUG — KHÔNG define → dead]
        & 2 → printspi(buf, len, print_to_spi_flash[0], print_via_memcpy[0])  → ghi log vào QSPI flash
```

- Comment tại `app_init.c:78`: *"print via smbus (bit 0), spi (bit 1), lan (bit 2), uart (bit 3)"* — dùng ký tự ASCII `'1'..'8'` để chọn.

- `_putc(char c)` (`app_cmdproc.c:1050`) — echo ký tự từng byte.

## 2. UART phần cứng

| define (`regAddrs.h`) | base |
|-----------------------|------|
| `AP_AON_UART10_BASE` | `0xE8003800` |
| `AP_AP_APB_UART1_BASE` | `0xE8004000` |
| `AP_AP_APB_UART2..4` | `+0x800` mỗi cái |

- `sys_uarts[]` (`extern UART_MV_REGS_t *sys_uarts[]`) — mảng con trỏ base, populate bởi tầng config UART (`mrvl_pxa920_uart_config.c`). `sys_uarts[0]` = **UART debug**.
- RX ngắt dùng `INTNUM_UART_INT_UART10` (SPI 14 → GIC ID 46, T7.5) ⇒ **UART debug = UART10 (`0xE8003800`, AON — luôn có điện kể cả khi ngủ)**. (INFERENCE mạnh: `setup_debug_read` gắn UART10 IRQ và `debug_print_w_id(0,...)` dùng `sys_uarts[0]` — hai cái cùng chỉ 1 cổng.)
- `UART_MV_REGS_t`: `union0.UART_THR`/`UART_RBR` (0x0 TX holding / RX buffer), `UART_LSR` (line status: **bit5 = THRE** "TX holding empty", **bit6 = TEMT** "TX shift empty"). `debug_print_w_id` chờ bit5; `dbg_outbuf_w_id` chờ bit6 (`0x40`).
- Cấu hình trong `dbg.c`: `UART_CONFIG _config = { 115200, UART_DATA_BITS_8, UART_STOP_BITS_1, UART_PARITY_NONE }` — nhưng `uartOpen()/uartSetConfig()/dbg_outbuf_init()` đều **bị comment** (`// uartOpen(...)`). ⇒ **UART không được FW cấu hình lại** — nó thừa hưởng 115200 8N1 từ BootROM/U-Boot. `dbg_cmd_init(_uart)` vẫn chạy.
- Driver đầy đủ `mrvl_pxa920_uart.c` (835 dòng, PXA920-style 16550) có sẵn nhưng đường log không dùng (chỉ poll THR trực tiếp).

## 3. `printspi` — ghi log vào QSPI flash (`hal_print.c:280`)
Khi `smbus_or_spi[0] & 2`: `printspi(read_ptr, len, print_to_spi_flash_0, print_via_memcpy_0)`:
- `print_to_spi_flash[] = "0=print_to_spi_flash"` → ký tự `'0'` → nhánh `if (print_to_spi_flash_0 == '1')` **false** ⇒ mặc định **không** ghi flash (chỉ memcpy vào buffer RAM). Có comment "still rialto register addresses" — chưa port hẳn sang quartz.
- Mục đích: lưu log ra flash để đọc post-mortem khi không có UART. Mặc định tắt.

## 4. `tick_handler` / `InitTimeBase` (nằm nhầm chỗ trong `hal_print.c:430-475`)

- `InitTimeBase(time_base)`: chọn `INTNUM_TIMEBASE_1MS`/`10MS`/`100MS` (mặc định **10MS**) → `intAttach(intnum, 0, tick_handler, 0)` + `intEnable`.
- `tick_handler`: `portSET_INTERRUPT_MASK_FROM_ISR()` → `xTaskIncrementTick()` → `portCLEAR_INTERRUPT_MASK_FROM_ISR(0)`. **Đây là nguồn tick FreeRTOS của R4** (10ms = 100Hz). PendSV pend bị comment (port ARM_CR4 dùng SWI/`vTaskSwitchContext`, T1.3).

## 8. FACT / INFERENCE / UNKNOWN

- **FACT**: chuỗi `SysApiDebug_Printf → SysApiPrint_Write → dbg_vprintf → vfstrfmt(_add_char) → debug_print → debug_print_w_id(0) → poll UART_LSR bit5 → UART_THR`; cổng `isLogOut`; 2 dòng lọc Component/Category bị comment trong `SysApiPrint_Write`; `smbus_or_spi[] = "8=..."` (mặc định UART); `printspi` mặc định không ghi flash; `HalApiJtag_*` stub; `InitTimeBase` mặc định 10ms tick; `setup_debug_read` gắn `INTNUM_UART_INT_UART10`; `dbg.c` `uartOpen`/`uartSetConfig` bị comment; UART bases `0xE8003800`/`0xE8004000+`.
- **INFERENCE**: UART debug = **UART10 (`0xE8003800`, AON domain)** — từ (a) RX IRQ = `INTNUM_UART_INT_UART10`, (b) `sys_uarts[0]` dùng cho cả TX log và RX. Chưa mở `mrvl_pxa920_uart_config.c` để xác nhận `sys_uarts[0]` = `0xE8003800`.
- **INFERENCE**: 115200 8N1 kế thừa từ BootROM/U-Boot vì FW không mở/cấu hình UART. Chưa kiểm BootROM (T12.2).
- **INFERENCE**: bộ lọc `*_DBG_MSG` có thể gate ở tầng macro (compile-time `#ifdef` hoặc kiểm `PrintBuf.debug_module` trong macro) trước khi gọi `ApiSysDebug_Printf` — chưa đọc hết định nghĩa `APP_DBG_MSG`/`APPKM_DBG_MSG`/`SYS_DBG_MSG`.
- **INFERENCE**: `PrintBuf` ring buffer không dùng trong đường log quartz (in thẳng UART). Có thể host đọc `PrintBuf` qua devmem ở build khác; ở đây gần như dead.
- **UNKNOWN**: `FW_PRINTBUFFER_SIZE`, `vfstrfmt` (format engine — trong `dprintf.c`?), `dbg_outbuf_*` (ring có/không dùng), `mrvl_pxa920_uart.c` có được link không (`uartOpen` bị comment nhưng `uart_handler` đọc register trực tiếp).
- **UNKNOWN**: `sys_uarts[]` được điền ở đâu (config layer), số phần tử.
- **UNKNOWN**: `isLogOut` được set true/false ở đâu, điều kiện nào (log level runtime của KM?).

## Tóm tắt (theo format skill)

**Hệ thống debug/UART của R4:**
Có hai đường in tách biệt. **Đường log runtime** (`APP_DBG_MSG`/`SysDebug_Printf`/`ApiSysDebug_Printf`, dùng khắp firmware) đi qua `SysApiPrint_Write` — chỉ bị chặn bởi 1 cờ toàn cục `isLogOut` (bộ lọc Component/Category đã bị comment) — rồi `dbg_vprintf` format thủ công từng ký tự, mỗi ký tự `debug_print` poll `UART_LSR` bit5 và ghi `UART_THR` của `sys_uarts[0]` trong critical section (blocking, chậm). Cổng vật lý là **UART10 `0xE8003800`** (AON, 115200 8N1 kế thừa từ BootROM; FW không cấu hình lại). **Đường console** (`app_cmdproc.c`, chỉ bản test ApplicationMrvl) in qua `HalApiPrint_printsmbus` chọn sink theo `smbus_or_spi[0]` — mặc định `'8'` = UART; RX qua ISR `uart_handler` trên `INTNUM_UART_INT_UART10` đẩy vào hàng đợi lệnh. Tùy chọn `printspi` (log ra QSPI flash) và `printsmbus` (aardvark) có mã nhưng mặc định tắt. JTAG (`HalApiJtag_*`) là stub no-op. `tick_handler`/`InitTimeBase` (tick FreeRTOS 10ms) cũng nằm trong `hal_print.c`.

**Call flow (một `APPKM_DBG_MSG` từ `LPPP_GPIO_Callback`):**
```
APPKM_DBG_MSG(-1,-1,"...")  → ApiSysDebug_Printf("APP",-1,-1,fmt,...)   [sys_debug_api.c:110]
  → EnterCritical → SysApiPrint_Write("APP",-1,-1,fmt,args)             [sys_print.c:61]
     → if(!isLogOut) return
     → dbg_vprintf(fmt,args) → vfstrfmt(_add_char,...)
        (mỗi ký tự) _add_char(c) → debug_print(&c) → debug_print_w_id(0,str)
           while(!(sys_uarts[0]->UART_LSR & 0x20));  sys_uarts[0]->union0.UART_THR = c;
     → dbg_vprintf("\r") → ExitCritical
```
