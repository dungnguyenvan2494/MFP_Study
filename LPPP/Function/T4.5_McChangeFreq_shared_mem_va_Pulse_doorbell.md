# T4.5 — `LPPP_McChangeFreq.h`: cửa sổ shared-mem M3↔R4, Pulse doorbell, `mc_qsclk` CONFIG

> Nguồn: `lppp_s800/ApplicationKM/LPPP_McChangeFreq.h` (toàn bộ), `.c` (T3.5).
> Bổ sung T3.5 (flow handler) với bản đồ địa chỉ/bit đầy đủ. Nối T0.2 §3.6 (kênh R4↔M3).

---

## 0 · Ba mảnh của IPC M3 ↔ R4 (kênh đổi tần số QSPI)

```
                     ┌──────────── R4 / LPPP ────────────┐
                     │  LPPP_McChangeFreq_handler [ISR]   │
                     └──┬──────────┬──────────────────┬───┘
   ① đọc dữ liệu        │          │ ③ ghi doorbell   │ ② nhận ngắt
   Mech Control Window  │          │ Pulse Tx         │ Pulse Rx → MC_LPP_IRQ0 (SPI 128)
   0xC057F000 + 0xFE0   │          │ 0xC0580000       │ 0xC0582000
                        ▼          ▼                  ▲
        ┌───────────────────── M3 / Machine Control ──┴───────────┐
        │  D-SRAM1 shared memory  (M3 view: 0x10090000 + 0xFE0)   │
        │  M3 ghi tần số đích vào FROM_MC1 (offset +0x0)          │
        └────────────────────────────────────────────────────────┘
```

`#undef DEBUG_ESL` (mọi nơi) → bản sản xuất dùng địa chỉ thật `0xC0...` (bản ESL dùng
`0x1FFFFFxx` cho mô phỏng).

## 1 · Shared memory D-SRAM1

| Ký hiệu | Giá trị | Ghi chú |
|---|---|---|
| `MECH_SHARE_MEM_BASEADDR` | `0x10090000` | shared-mem (D-SRAM1) **nhìn từ phía M3** |
| `MECH_SHARE_MEM_LPPP_OFS` | `0xFE0` | vùng con MC⇔LPPP |
| `MECH_CONTROL_WINDOW_BASEADDR` | `0xC057F000` | cửa sổ R4 truy cập vào D-SRAM1 (qua khối UL/PI) |
| `FROM_MC1..4_OFS` | `0x0 / 0x4 / 0x8 / 0xC` | **M3 ghi → R4 đọc** (4 word) |
| `FROM_LPPP1..4_OFS` | `0x10 / 0x14 / 0x18 / 0x1C` | **R4 ghi → M3 đọc** (4 word) |

R4 đọc tần số đích: `*(uint32_t*)(MECH_CONTROL_WINDOW_BASEADDR + MECH_SHARE_MEM_LPPP_OFS + FROM_MC1_OFS)`
= `*(uint32_t*)(0xC057F000 + 0xFE0 + 0x0)` = `*(uint32_t*)0xC057FFE0`.

⚠ Handler **không dùng** `FROM_LPPP*` (R4 báo M3 xong bằng Pulse Tx, không qua shared-mem).

## 2 · `LPPP_mc_window_set()` — trỏ cửa sổ vào D-SRAM1

```c
temp_addr = MC_APB_CONFIG_BASEADDR + MC_APB_CONFIG_MODE_CF0_OFS;   // = 0xC0584000 + 0x0
temp_data = *temp_addr;
temp_data &= ~MC_APB_CONFIG_MODE_CF0_MODE_ADR_MASK;                // xoá bits[35:12] (mask = 0xFFFFFF << 12)
temp_data |= (MECH_SHARE_MEM_BASEADDR & MC_APB_CONFIG_MODE_CF0_MODE_ADR_MASK);   // = 0x10090000 & (0xFFFFFF<<12)
*temp_addr = temp_data;                                            // MODE_ADR = "MC D-SRAM1"
```
`MODE_CF0.MODE_ADR` (bit 12, mask 24-bit) = địa chỉ base mà cửa sổ Mech Control trỏ tới. Gọi ở
`LPPP_McChangeFreq_init()` (1 lần) **và** đầu mỗi `LPPP_McChangeFreq_handler()`.

| Ký hiệu | Giá trị |
|---|---|
| `MC_APB_CONFIG_BASEADDR` | `0xC0584000` |
| `MC_APB_CONFIG_MODE_CF0_OFS` | `0x0` |
| `MODE_CF0_MODE_ADR_SHIFT` / `_MASK` | 12 / `0xFFFFFF << 12` |
| `MODE_CF1_OFS` / `SPARE_CUSTOM_OFS` | `0x4` / `0x8` |
| `INT_DEBUG_MC_OFS` / `MSK_DEBUG_MC_OFS` | `0x800` / `0x804` |

## 3 · Pulse Tx / Pulse Rx — doorbell

### Pulse Tx (`0xC0580000`) — R4 → M3
| Offset | Tên | Ghi chú |
|---|---|---|
| `0x0` | `SET_SUB_MAIN` | ghi `1 << 13` (`LPPP` field) = báo M3 "đã xong đổi tần số" |
| `0x4` | `CLR_SUB_MAIN` | |
| `0x8` | `MONI_TX_SUB_MAIN` | monitor |

`PULSE_TX_SET_SUB_MAIN_LPPP_SHIFT = 13`, `_MASK = 1`. Cuối `LPPP_McChangeFreq_handler`:
```c
*(uint32_t*)(PULSE_TX_BASEADDR + PULSE_TX_SET_SUB_MAIN_OFS) |= (1 << 13);   // = *0xC0580000 |= 0x2000
```

### Pulse Rx (`0xC0582000`) — M3 → R4
| Offset | Tên |
|---|---|
| `0x0` | `INT_SUB_MAIN` |
| `0x4` | `MSK_SUB_MAIN` |
| `0x8` | `MONI_RX_SUB_MAIN` |

M3 gửi pulse → sinh ngắt `MC_LPP_IRQ0` = SPI 128 (`LPPP_inc.h`, T3.5) → `LPPP_McChangeFreq_handler`.
_(Handler không đọc thanh ghi Pulse Rx trực tiếp — nó chỉ được gọi qua `intAttach`.)_

## 4 · `mc_qsclk` ClkGen — thanh ghi cấu hình clock QSPI của M3

`PMU_CLK_RST_GEN_BASEADDR = 0xE8240000` (= `PMU_CONFIG_STATUS`, cùng vùng PMU).

| Thanh ghi | Offset | Địa chỉ |
|---|---|---|
| `MC_QSCLK_CONFIG` | `0x1B0` | `0xE82401B0` |
| `MC_QSCLK_STATUS` | `0x1B4` | `0xE82401B4` |

### Bit field `MC_QSCLK_CONFIG` (`0xE82401B0`)
| Field | SHIFT / MASK | Ý nghĩa |
|---|---|---|
| `CLKEN` | 1 / `0x1` | 1 = clock bật |
| `PREDIVEN` | 2 / `0x1` | 1 = pre-divider bật (mc_qsclk **luôn chia 2** bất kể) |
| `LODIV` | 8 / `0xFF` | nửa chu kỳ low (8-bit) |
| `HIDIV` | 16 / `0xFF` | nửa chu kỳ high (8-bit) |

### Bit field `MC_QSCLK_STATUS` (`0xE82401B4`)
| Field | SHIFT / MASK | Ý nghĩa |
|---|---|---|
| `CLKGATE` (CLKGATED) | 7 / `0x1` | 1 = clock đang bị gate (chưa ổn định) — poll cho tới khi = 0 |

### Trình tự trong handler (T3.5 §3.3, giờ có địa chỉ)
```c
temp_data = *0xE82401B0;
temp_data &= ~(1 << 1);           *0xE82401B0 = temp_data;   // CLKEN = 0

// div đã tính: div = MC_PLL_CLK / target; nếu lẻ → (div+1)/2 else div/2   (mc_qsclk luôn /2)
temp_data &= ~(0xFF << 8);        temp_data |= (LODIV << 8);   // LODIV = (div/2)+1 nếu lẻ else div/2
temp_data &= ~(0xFF << 16);       temp_data |= ((div/2) << 16);// HIDIV = div/2
temp_data |= (1 << 2);            // PREDIVEN = 1
temp_data |= (1 << 1);           *0xE82401B0 = temp_data;      // CLKEN = 1

// poll: while (*0xE82401B4 & (1<<7)) { timeout CLK_STATUS_TIMEOUT+5 tick } → thất bại: return (không pulse)
*0xC0580000 |= (1 << 13);        // Pulse Tx SET_SUB_MAIN.LPPP — báo M3 xong
```

## 5 · Hằng số clock

| Ký hiệu | Giá trị | Ghi chú |
|---|---|---|
| `MC_PLL_CLK` | `2100000000` | 2.1 GHz (= `SSPLL_MC_DEFAULT`, T4.3) |
| `MC_QSCLK_DIV_MIN` | `8` | → tần số max `2100/8` = **262.5 MHz** |
| `MC_QSCLK_DIV_MAX` | `1020` | → tần số min `2100/1020` ≈ **2.06 MHz** |
| `CLK_STATUS_TIMEOUT` | `10` ms | AR.1067928 (2018/12/10): **5→10** — với 5, kết quả tính ra 1, xử lý ở biên tick → **timeout giả** |

## 6 · Tóm tắt (theo format skill)

**1. Tồn tại để làm gì:** `LPPP_McChangeFreq.h` khai báo bản đồ IPC M3↔R4 cho việc đổi tần số QSPI
của M3: (a) **shared-mem D-SRAM1** — M3 ghi tần số đích vào `FROM_MC1` (R4 đọc qua cửa sổ Mech
Control `0xC057F000 + 0xFE0`); (b) **cửa sổ** — `LPPP_mc_window_set()` ghi `MC_APB_CONFIG.MODE_CF0.
MODE_ADR` (`0xC0584000`) trỏ vào `0x10090000`; (c) **doorbell** — M3→R4 = Pulse Rx `0xC0582000`
→ ngắt `MC_LPP_IRQ0` (SPI 128); R4→M3 = Pulse Tx `0xC0580000` `SET_SUB_MAIN` bit 13. Việc đổi
clock thật: RMW `MC_QSCLK_CONFIG` (`0xE82401B0`, CLKEN/PREDIVEN/LODIV/HIDIV), poll `MC_QSCLK_STATUS.
CLKGATE` (`0xE82401B4` bit 7).

**2. Bảng địa chỉ:** §1-§5.

**3. File đã tham chiếu:**
- `ApplicationKM/LPPP_McChangeFreq.h` (toàn bộ)
- `ApplicationKM/LPPP_McChangeFreq.c` (T3.5)

**4. Đã xác nhận / phát hiện:**
- ✅ Shared-mem: M3 view `0x10090000+0xFE0`; R4 view qua cửa sổ `0xC057F000+0xFE0`.
  `FROM_MC1..4` (M3→R4) offset 0-0xC; `FROM_LPPP1..4` (R4→M3) offset 0x10-0x1C. Handler chỉ đọc `FROM_MC1`.
- ✅ `LPPP_mc_window_set` ghi `MC_APB_CONFIG.MODE_CF0.MODE_ADR` (bit 12, mask 24-bit) = `0x10090000`.
- ✅ Pulse Tx `0xC0580000` `SET_SUB_MAIN` bit **13** (`PULSE_TX_SET_SUB_MAIN_LPPP`) = R4 báo M3 xong.
- ✅ Pulse Rx `0xC0582000` → `MC_LPP_IRQ0` (SPI 128).
- ✅ `MC_QSCLK_CONFIG` @ `0xE82401B0`: CLKEN bit 1, PREDIVEN bit 2, LODIV [15:8], HIDIV [23:16].
  `MC_QSCLK_STATUS` @ `0xE82401B4`: CLKGATE bit 7.
- ✅ Dải tần số M3 QSPI: 2.06 MHz (`div 1020`) .. 262.5 MHz (`div 8`).
- ✅ `CLK_STATUS_TIMEOUT` 5→10 ms (AR.1067928 — tránh timeout giả ở biên tick).
- ✅ `DEBUG_ESL` = bản đồ địa chỉ mô phỏng thay thế; `#undef` mọi nơi → bản sản xuất dùng `0xC0...`.
