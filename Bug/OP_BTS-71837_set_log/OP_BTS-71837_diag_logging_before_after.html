OP_BTS-71837: log chẩn đoán, bản before / after

30 chỉnh sửa trên 9 file (6 file kernel, 3 file ứng dụng). Mọi dòng log mới đều có tiền tố OP_BTS-71837: để grep. Không đổi logic, chỉ thêm log (hai chỗ nâng dev_dbg lên dev_warn). Đã kiểm tra: mọi chỉnh sửa khớp đúng một vị trí trong source hiện tại, và patch áp sạch bằng git apply --check.

Chưa kiểm tra: phần kernel chưa được biên dịch (không có toolchain và cây kernel đã cấu hình trong môi trường này). Phần hàm dump của ứng dụng đã được biên dịch riêng bằng g++ (C++98, -Wall -Wextra) và chạy thử, thấy đúng pid/comm/cwd/exe của tiến trình giữ thư mục. Hãy biên dịch kernel trước khi nạp lên máy. Các dòng dump_stack() chỉ nằm ở điểm hiếm (reset, tắt nguồn cổng, ngắt kết nối logic) nên không gây ồn khi chạy bình thường. Nhánh xHCI port event chạy trong ngữ cảnh ngắt và console là UART 115200, nên chỉ in sự kiện bất thường (kết nối bình thường không in).

Cách dùng

git apply OP_BTS-71837_diag_logging.patch (tại thư mục gốc repo), build kernel và app, rồi lọc log bằng grep OP_BTS-71837. Sau điều tra, gỡ bằng git apply -R. Kernel cần thấy dòng mức warn: dev_warn, xhci_warn và printk(KERN_WARNING) đều lọt qua bộ lọc console mà dòng INFO không qua được. Log của ứng dụng đi qua printf như các dòng BSP hiện có.
