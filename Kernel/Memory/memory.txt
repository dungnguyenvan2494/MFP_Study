Tôi muốn nghiên cứu cực kỳ chuyên sâu về Linux Kernel Memory Management trên kiến trúc ARM64.

Nguồn lý thuyết ban đầu là Chapter 8 – Memory Management trong tài liệu PDF tôi cung cấp.
Tuy nhiên tài liệu này chủ yếu mô tả Linux 2.6 và có nhiều phần mang tính historical/x86-specific.

Mục tiêu của tôi KHÔNG phải học lại Linux 2.6.

Mục tiêu là:

1. Dùng Chapter 8 làm nền tảng concept.
2. Sau đó mapping từng concept sang implementation Linux kernel trên ARM64.
3. Ưu tiên Linux 5.4.x.
4. Khi cần, so sánh với Linux 6.x để thấy implementation đã thay đổi như thế nào.
5. Phải đọc source code thật và verify function/struct/file.
6. Không được tự suy đoán call flow.
7. Nếu tài liệu nói một cơ chế không còn phù hợp với ARM64 hiện đại, phải chỉ rõ:
   - tài liệu nói gì
   - ARM64 thực tế làm gì
   - source code ở đâu
   - cơ chế cũ được thay thế như thế nào

Thứ tự mình khuyên bạn học

Đừng đi đúng thứ tự PDF 1:1. Với ARM64, nên đi theo chuỗi này:

ARM64 VA/PA + MMU → memblock → struct page → zones → buddy → PCP → SLUB → kmalloc → vmalloc → page tables/TLB → reclaim/compaction → CMA/DMA.

Lý do là tài liệu bắt đầu khá sớm bằng struct page, zones và buddy , rồi mới tới SLAB và vmalloc/non-contiguous memory ở cuối chương . Với ARM64, chen MMU/page-table + memblock vào trước sẽ giúp toàn bộ flow phía sau dễ nối lại hơn rất nhiều.

Một điểm đặc biệt mình muốn bạn giữ trong prompt: đừng học HIGHMEM như thể ARM64 hiện đại là x86 32-bit. Hãy biến nó thành một bài “PDF concept → ARM64 implementation → historical difference”. Đây chính là chỗ tài liệu cũ dễ làm người học ARM64 bị rối.
