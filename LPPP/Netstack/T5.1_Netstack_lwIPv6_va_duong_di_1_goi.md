## 1 · GMAC nằm **trong Iris** — driver kiểu BMU/LE (SysKonnect)

`hal_lan.c` include `eth_bmu.h` — driver GMAC gốc SysKonnect/Yukon (`SK_PACKET`, `SC_STAT_RST`,
BMU = **Buffer Management Unit**, LE = **List Element** = descriptor). Thanh ghi LAN/LED nằm ở
`SB_IRIS0_ADDR + LED_CONTROL_REG_OFF` (`hal_lan.c:259` — GbE trong Iris SB0, `iris.md §2`).

### Cấu trúc DMA (đặt trong `.netbufsec` — vùng 80KB NOCACHE, T1.6)
```c
SK_PACKET  ReceivePacketTable[RX_MAX_NBR_BUFFERS]   __attribute__((section(".netbufsec")));  // buffer RX — GMAC DMA GHI vào
SK_PACKET  TransmitPacketTable[TX_MAX_NBR_BUFFERS]  __attribute__((section(".netbufsec")));  // buffer TX — GMAC DMA ĐỌC
ETH_LE_TABLE  STATUS_LET  __attribute__((section(".netbufsec")));   // Status BMU descriptor table
ETH_LE_TABLE  TX_LET      __attribute__((section(".netbufsec")));   // TX LE table
ETH_LE_TABLE  RX_LET      __attribute__((section(".netbufsec")));   // RX LE table
```
`.netbufsec` = NOCACHE vì **GMAC DMA truy cập trực tiếp** — D-cache R4 không coherent. Nhánh
`#else` (`!LET_IN_TCM`) có `#error` bắt xác minh: *"either verify GMAC DMA does NOT access the
structs or implement flush/invalidate"*.

### Buffer pool lwIP (đặt trong `.bufpools` — cũng trong 80KB NOCACHE, `cc.h:63-73`)
```c
extern u8_t __attribute__((section(".bufpools"))) memp_memory_PBUF_POOL_base[];
extern u8_t __attribute__((section(".bufpools"))) memp_memory_PBUF_POOL_RX_base[];
extern u8_t __attribute__((section(".bufpools"))) memp_memory_POOL_64_base[];
extern u8_t __attribute__((section(".bufpools"))) memp_memory_POOL_128_base[];
extern u8_t __attribute__((section(".bufpools"))) memp_memory_POOL_256_base[];
extern u8_t __attribute__((section(".bufpools"))) memp_memory_POOL_512_base[];
extern u8_t __attribute__((section(".bufpools"))) memp_memory_POOL_1024_base[];
extern u8_t __attribute__((section(".bufpools"))) memp_memory_POOL_1600_base[];   // KM: cho IPv6 ping ≥ 945B
```
`PBUF_POOL` / `PBUF_POOL_RX` = pbuf pool của lwIP; `POOL_64..1600` = memp pool cố định kích thước.

## 2 · `SysLan_Init(mem, memsize)` (`sys_lan_init.c:95-201`) — dựng netif

```c
tcpip_init(NULL, NULL);                  // lwip_init + ip_init + memp_init + tạo task tcpip

netif_add(&netIf, &xIpAddr=0, &xIpAddr=0, &xIpAddr=0, NULL,
          ethernetif_init,              // hàm init interface
          ethernet_input);              // hàm input — ★ ethernet_input, KHÔNG phải tcpip_input
                                        //   ⇒ gói xử lý NGAY trong task ETH_I, không hoãn sang task tcpip
netif_set_default(&netIf);

// MAC/IGMP/MLD filter — hầu hết #ifdef OFF ("not finished yet in hal")

if (HalApiLan_LinkIsUp())  netif_set_link_up(&netIf);   // chỉ set NETIF_FLAG_LINK_UP
else                       netif_set_link_down(&netIf);  // interface chưa "up" (NETIF_FLAG_UP)
```
IP ban đầu = `0.0.0.0`; IP thật do IOCTL từ Linux driver đặt sau (`CHANGED_NETWORK_CREDENTIALS`,
`AppThread_Main.md`). `SysLan_Init` gọi 1 lần trong `SysApi_InitApplModules` (T1.5); trên resume
dùng `SysLan_setup_gigabit_core()` (`sys_lan_init.c:226`) — nạp lại GMAC (từ `DRIVER_GOODBYE`,
`SysSystem_ThreadMain.md §C`).

## 3 · Đường đi 1 gói NHẬN (RX)

```
① Gói Ethernet tới GMAC (trong Iris SB0)
     GMAC DMA ghi vào ReceivePacketTable[k] + cập nhật RX_LET (RX List Element)
     → sinh ngắt EMAC  (EMAC_ISR.c) → HalEth_bmu_isr() [nếu STATUS_BMU_ISR_MODE] → xSemaphoreGive(xSemaphore)
② task "ETH_I" (ethernetif_input, ethernetif.c:274) — thức khi có semaphore:
     [không ISR mode] HalEth_bmu_tsr(MAXIMUM_RX_LE)     xử lý status LE
     n = HalApiLan_GetRxPacketCount()
     for i in 0..n:
        p = low_level_input()  (ethernetif.c:178):
           ┌─ HalApiCpu_interrupt_control(DISABLE)
           ├─ HalApiLan_ReceiveWithDataPushCallback(&p)   lấy pbuf từ RX buffer
           ├─ HalApiCpu_interrupt_control(restore)
           ├─ if (!p) return NULL
           │
           ├─ [MRVL_FILTER_ENABLED] if (RedirectTraffic):    ← ★ Linux driver ĐANG có mặt
           │      SysApiLan_PacketForwardToDriver(p->payload, p->tot_len)   → HCI FIFO → Linux (T6)
           │      pbuf_free(p); return NULL                    (gói KHÔNG vào lwIP)
           │
           ├─ [MRVL_FILTER] ★ FILTER STAGE 1 (phần mềm — HW pattern match đã chạy TRƯỚC trong GMAC/Iris)
           │      if (SysFilter_Execute_Filter(p->payload, p->tot_len, 0) == RC_DISCARD_PACKET):
           │           pbuf_free(p); return NULL
           │
           ├─ saved_rawpacket = pbuf_alloc(PBUF_RAW, 0, PBUF_REF)   lưu REF cho FILTER STAGE 2
           │      saved_rawpacket->payload = p->payload; ->tot_len = p->tot_len
           │      (KHÔNG pbuf_chain — chain làm tăng refcount → assertion ở ip_output_if với ICMP)
           │
           ├─ [ETH_PAD_SIZE] pbuf_header(p, ETH_PAD_SIZE)   thu lại word đệm
           └─ return p
        xNetIf->input(p, xNetIf)  = ethernet_input (lwIP)
           → phân giải EtherType: ARP → etharp_input ; IPv4/IPv6 → ip_input → udp/tcp/icmp
           → tới proxy (LLMNR/NBNS/mDNS/SNMP — T5.3/5.4) hoặc socket (T... sdk)
        if != ERR_OK: pbuf_free(p)
     HalLan_fill_receive_queue(1)          nạp lại buffer trống vào RX ring
     HalLan_free_buffers_from_queue_index(5)  giải phóng buffer TX đã gửi
     nếu hết gói: HalApiEth_unmask_irqs() ; xSemaphoreTake(xSemaphore, portMAX_DELAY)  ← block
```

### Đường GỬI (TX)
```
proxy/socket → udp_send/tcp_write → ip_output → netif->output = ethernetif_output → etharp_output
   → (ARP resolved) → netif->linkoutput = low_level_output (ethernetif.c:116)
        copy pbuf → TransmitPacketTable[k] + TX_LET → kick GMAC DMA
```

## 4 · Hai chế độ — `RedirectTraffic`

| | `RedirectTraffic == true` | `RedirectTraffic == false` |
|---|---|---|
| Khi nào | **Linux driver có mặt** (host thức, đã `DRIVER_HELLO`) | host ngủ / chưa boot |
| Gói RX | **mọi gói** → `SysApiLan_PacketForwardToDriver` → HCI FIFO → Linux | qua `SysFilter` → lwIP → proxy |
| Vai trò LPPP | chỉ là "ống dẫn" gói lên Linux | **proxy thật sự** — trả lời thay host |

Đây là cốt lõi lý do LPPP tồn tại: khi host ngủ, `RedirectTraffic = false`, LPPP nhận gói, lọc
(SysFilter), và proxy trả lời các truy vấn tầm thường mà không đánh thức A72.

## 6 · Tóm tắt (theo format skill)

**1. Tồn tại để làm gì:** `Netstack/lwipv6` là fork lwIP có IPv6 của Marvell. `SysLan_Init` gọi
`tcpip_init` + `netif_add(..., ethernet_input)` (xử lý gói ngay trong task `ETH_I`, không hoãn) +
set link. GMAC nằm **trong Iris SB0**, driver kiểu BMU/LE (SysKonnect): descriptor table
`RX_LET/TX_LET/STATUS_LET` + buffer `Receive/TransmitPacketTable` đặt trong `.netbufsec` (NOCACHE,
GMAC DMA truy cập); pbuf pool trong `.bufpools`. Task `ETH_I` vòng lặp: semaphore ← ngắt EMAC →
`low_level_input` (lấy pbuf, nếu `RedirectTraffic` thì đẩy thẳng qua HCI FIFO cho Linux, else qua
**SysFilter stage 1** rồi `xNetIf->input` = `ethernet_input` → ARP/IP → proxy/socket).

**2. Call flow:** §3.

**4. Đã xác nhận / phát hiện:**
- ✅ GMAC = GbE **trong Iris SB0** (`SB_IRIS0_ADDR`), driver BMU/LE (SysKonnect `eth_bmu.h`).
- ✅ `RX_LET/TX_LET/STATUS_LET` + `Receive/TransmitPacketTable` → `.netbufsec` (NOCACHE, DMA).
  `PBUF_POOL*` + `POOL_64..1600` → `.bufpools` (NOCACHE). `POOL_1600` thêm cho IPv6 ping ≥945B.
- ✅ `netif_add` dùng `ethernet_input` (không `tcpip_input`) → xử lý gói trong task `ETH_I` trực tiếp.
- ✅ `low_level_input`: (a) `RedirectTraffic` → `SysApiLan_PacketForwardToDriver` (HCI FIFO); (b) else
  → `SysFilter_Execute_Filter(stage 0)` = **Filter Stage 1**; (c) lưu `saved_rawpacket` (PBUF_REF)
  cho Filter Stage 2 — **không** `pbuf_chain` (tránh assertion refcount ở `ip_output_if` với ICMP).
- ✅ Task `ETH_I` block trên `xSemaphore` khi hết gói; ngắt EMAC give semaphore. `HalLan_fill_receive_queue`
  nạp lại buffer, `HalLan_free_buffers_from_queue_index(5)` giải phóng TX.
- ✅ IP ban đầu `0.0.0.0` — Linux driver đặt IP thật qua IOCTL sau.
- ✅ `SysLan_setup_gigabit_core()` = nạp lại GMAC trên resume/`DRIVER_GOODBYE`.

**Gợi ý:** `kernel-arch-diagram` để vẽ đường đi gói RX (GMAC→BMU→ETH_I→SysFilter→lwIP→proxy).
