# 10. CODE EXPLANATION

Sau những đoạn code quan trọng, hiển thị:

```text
What happens?
```

```text
How the compiler sees it
```

hoặc:

```text
Memory view
```

Ví dụ:

```cpp
Base* p = new Derived;
p->foo();
```

phải có phần giải thích:

```text
Base*
   ↓
object address
   ↓
vptr
   ↓
vtable
   ↓
Derived::foo()
```
