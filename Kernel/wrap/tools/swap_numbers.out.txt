1. Vi du RAM 1024 MiB + swap 2048 MiB (page 4 KiB)
========================================================================
RAM page frame                    :     262144
swap header last_page             :     524287
si->max (maxpages)                :     524288
si->pages (slot dung duoc, tru header): 524287
swap_map = vzalloc(maxpages)      :     524288 byte = 512 KiB (1 byte/slot)
so cluster (256 slot/cluster)     :       2048
cluster_info (chi SSD/non-rot)    :      16384 byte = 16 KiB (gia dinh 8 byte/cluster)
so address_space cua swap cache   :         32 (moi cai phu 16384 slot = 64 MiB)
swap_cgroup: SC_PER_PAGE          :       2048 entry/page
swap_cgroup: ctrl->length         :        256 page = 1.00 MiB (+ mang con tro 2048 byte)
Tong metadata/so voi du lieu swap : 0.074 %
vm_swap_full() dung khi free_swap*2 < total -> free < 262143.5 slot (~50%)

5. Giai ma mot so gia tri swap_map
========================================================================
  0x00: slot trong (free)
  0x40: swap count=0, SWAP_HAS_CACHE=1
  0x01: swap count=1, SWAP_HAS_CACHE=0
  0x41: swap count=1, SWAP_HAS_CACHE=1
  0x03: swap count=3, SWAP_HAS_CACHE=0
  0x43: swap count=3, SWAP_HAS_CACHE=1
  0x3e: swap count=62, SWAP_HAS_CACHE=0
  0x3f: SWAP_MAP_BAD: header/bad block/cluster dang discard
  0xbf: SWAP_MAP_SHMEM: slot cua shmem/tmpfs
  0xbe: count da dat SWAP_MAP_MAX, phan cao nam o continuation page

7. Dem so lan lay khoa toan cuc khi cap/tra 1 000 000 slot (vi du E)
========================================================================
Khong co slot cache : cap 1000000 lan get_swap_pages(1) -> 1000000 lan swap_avail_lock + 1000000 lan si->lock
                      tra 1000000 lan swapcache_free_entries(1) -> 1000000 lan si->lock
Co slot cache (64)  : cap -> 15625 lan refill (moi lan 1 swap_avail_lock + 1 si->lock) + 1000000 lan alloc_lock (mutex per-CPU, hau nhu khong tranh chap)
                      tra -> 15625 lan swapcache_free_entries(64) (sort theo area, 1 si->lock/lo) + 1000000 lan free_lock (spinlock per-CPU)
Ti le giam khoa toan cuc: 64 lan
