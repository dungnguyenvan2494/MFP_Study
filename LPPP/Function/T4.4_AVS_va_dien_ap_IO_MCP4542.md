## 1 · AVS — Quartz core (`avs.c`)

### Thanh ghi
```c
volatile int32_t *quartz_avs_control_reg    = (uint32_t *)0xE8244000;  // AVS_CONTROL: ENABLE, RST_B
volatile int32_t *quartz_avs_vdd_limits_reg = (uint32_t *)0xE8244008;  // AVS_VDDLIMIT: HIGH_VDD_LIMIT, LOW_VDD_LIMIT (mã 6-bit)
volatile int32_t *quartz_efuse_reg          = (uint32_t *)0xE8002080;  // efuse mirror

#define EFUSE_AVS_VALID_BIT       113
#define EFUSE_AVS_LOW_VDD_OFFSET   81
#define EFUSE_AVS_HIGH_VDD_OFFSET  87
#define EFUSE_AVS_MASK           0x3F     // mã 6-bit
```

### `avs_set_from_efuse(millivolts)` (`avs.c:210-240`) — gọi `avs_set_from_efuse(1097)` từ `main()`
```c
if (quartz_efuse_reg[113/32] >> (113%32)) {          // efuse VALID bit set?
    avs_high = (efuse[87/32] >> (87%32)) & 0x3F;     // đọc mã 6-bit
    avs_low  = (efuse[81/32] >> (81%32)) & 0x3F;
#if 0
    status = avs_set_high_low(avs_low, avs_high);    // ★ ĐƯỜNG THẬT — BỊ TẮT
#else
    "AVS eFUSE is valid."
    "SET SB Voltage (1097mv) [eFuse low: %d - high: %d]"
    status = avs_millivolts_set(millivolts);         // ← LUÔN đặt 1097, chỉ IN mã efuse
#endif
} else {
    "AVS eFUSE is NOT valid - setting to 1097 mV"
    status = avs_millivolts_set(millivolts);
}
```

🔴 **`avs_set_from_efuse` là tên gọi sai:** đường hiệu chỉnh theo lô chip (`avs_set_high_low(avs_low,
avs_high)`) bị **`#if 0`**. Nó đọc + in mã efuse để log, nhưng **luôn đặt 1097 mV cố định** dù
efuse hợp lệ hay không. (Trái với `ap806_update_voltage` cho A72 — dùng efuse thật.)

### `avs_millivolts_set(mV)` (`avs.c:194-208`)
```c
avs_volt_code = lookup_AVS_Volt_Code(mV);            // → mã gần nhất (747..1342 mV, bước ~11.7 mV)
"AVS %dmV => code: %d"
status = avs_set_high_low(avs_volt_code, avs_volt_code);   // high = low = cùng mã
cpu_spin_delay(5000);                                // 5 ms settle
```
`lookup_AVS_Volt_Code(v)` (`avs.c:44-...`): chuỗi `if (v <= AVS_VOLTS_747MV) return AVS_VOLT_CODE_0_747_MV;
... if (v <= AVS_VOLTS_1342MV) ...` — chọn mã có ngưỡng đầu tiên `>= v`. Dải **0.747 V .. 1.342 V**.

### `avs_set_high_low(low, high)` (`avs.c:167-192`)
```c
if (low < CODE_0_747 || low > CODE_1_342)  { "AVS low out of range"; return -1; }
if (high < CODE_0_747 || high > CODE_1_342) { "AVS high out of range"; return -1; }

reg = *quartz_avs_vdd_limits_reg;                    // RMW 0xE8244008
reg = AVS_VDDLIMIT_HIGH_VDD_LIMIT_REPLACE_VAL(reg, high);
reg = AVS_VDDLIMIT_LOW_VDD_LIMIT_REPLACE_VAL(reg, low);
*quartz_avs_vdd_limits_reg = reg;

reg = *quartz_avs_control_reg;                       // RMW 0xE8244000
reg = AVS_CONTROL_ENABLE_REPLACE_VAL(reg, 1);        // bật AVS
reg = AVS_CONTROL_RST_B_REPLACE_VAL(reg, 1);         // nhả reset AVS
*quartz_avs_control_reg = reg;
return 0;
```
Đặt high == low == cùng mã ⇒ AVS **khoá điện áp ở một mức** (không cho phần cứng AVS tự dao động
trong khoảng). `avs_millivolts_get()` đọc lại `AVS_VDDLIMIT.HIGH_VDD` → `lookup_AVS_Code_Volt()`.

## 2 · MCP4542 — điện áp IO của Quartz (`hal_main.c`)

MCP4542 = **chiết áp số 7-bit** trên bo, nối vào mạch phản hồi của regulator IO. LPPP đổi wiper
code qua I2C1 để tinh chỉnh VDDIO.

### Hằng số (`hal_main.c:70-81`)
```c
#define MCP4542_ADDRESS   0x2d                              // slave I2C1
#define CMD_WRITE_DATA    0
#define VWIPER_ADDR       0
#define CMD_SET_WIPER   ((VWIPER_ADDR << 4) | (CMD_WRITE_DATA << 2))   // = 0x00  "write volatile wiper 0"
#define DATA_CMD_WRITE    (~DW_I2C_IC_DATA_CMD_CMD_MASK)               // = 0xFFFFFEFF (clear bit 8 = R/W→write)
#define DATA_CMD_DATA(v)  ((uint32_t)v << DW_I2C_IC_DATA_CMD_DAT_SHIFT) // << 0  ← ĐÚNG (khác bug ở i2c_regmasks.h)
#define DATA_CMD_STOP     DW_I2C_IC_DATA_CMD_STOP_MASK                 // bit 9
```

### `MCP4542_i2c_configure()` (`hal_main.c:755-770`)
```c
i2cRegs = (APB_DW_I2C0_REGS_t *)AON_I2C1_BASE;      // 0xE8006800
i2c_init_new(i2cRegs);
i2c_IC_TAR(i2cRegs, 0x2d);
i2cRegs->IC_INTR_MASK = 0xFFFF;
i2cRegs->IC_ENABLE = 0; i2cRegs->IC_CON = 0x63; i2cRegs->IC_ENABLE = 1;
```
(⚠ driver Marvell này — HCNT/LCNT không set, dùng giá trị reset; `IC_SDA_SETUP` bug 300→44 —
xem `Core/I2C.md §3.5`. Vô hại vì MCP4542 không tới hạn tốc độ.)

### `io_millivolts_set(millivolts)` (`hal_main.c:773-800`)
```c
if (!(i2cRegs->IC_ENABLE_STATUS & 1))  MCP4542_i2c_configure();

if (millivolts > 1200) millivolts = 1200;           // CLAMP
if (millivolts < 1000) millivolts = 1000;

wiper_code = (12000250 - 10000 * millivolts) / 15750;   // ★ NGHỊCH ĐẢO: mV cao → code thấp
   //  1000 mV → ~127     1100 mV → ~63     1200 mV → ~0     (7-bit, 0..127)
   // comment: "not exactly correct, but close enough given our usage and resistor tolerances"

i2cRegs->IC_DATA_CMD = DATA_CMD_WRITE & DATA_CMD_DATA(CMD_SET_WIPER);       // byte 0 = 0x00 (command/addr)
i2cRegs->IC_DATA_CMD = DATA_CMD_WRITE & (DATA_CMD_STOP | DATA_CMD_DATA(wiper_code));  // byte 1 = code + STOP

cpu_spin_delay(1000);                                // 1 ms
```
2 byte: `[0x00 command] [wiper_code | STOP]`. `DATA_CMD_WRITE & (...)` = mẫu "clear bit R/W (bit 8)
rồi giữ nguyên data + STOP" — hoạt động vì `DATA_CMD_WRITE = ~CMD_MASK`.

### `io_update_voltage()` (`hal_main.c:989-1010`) — gọi từ `init_thread` (`hal_main.c:187`)
```c
int millivolts = 1100;                               // mặc định
setup_debug_uart_w_id(1, 200000000, 115200);
if (IO_VOLT_PROMPT_DURATION_MS > 0)
    millivolts = prompt_for_desired_io_voltage(1100); // prompt UART tương tác — CHỈ bring-up/dev
io_millivolts_set(millivolts);
cpu_spin_delay(IO_VOLT_PROMPT_DURATION_MS * MILLISEC);
for (i = 0; i < gINA219Cfg count; i++)  setI2CINA219Cfg(&gINA219Cfg[i]);   // cấu hình cảm biến dòng INA219 (đo/debug)
```

`prompt_for_desired_io_voltage(default)` (`hal_main.c:801+`): set MPP 11/19 của AP806 sang function
3 (UART) qua pinmux `0xCE6F4000`, cấu hình UART1, "Desired IO voltage: ", đọc chữ số trong
`IO_VOLT_PROMPT_DURATION_MS`. Chỉ dùng khi bring-up.

### Vị trí trong `init_thread` (`hal_main.c:166-192`)
```
init_thread:
   ... LPPP_KM_Init · get_ddr_memory_size · [Eagle3 100ms wait] ...
   pmu_phase(pmu_ap_link_up)     ← ap806_update_voltage() (A72 VDD, T4.2)
   pmu_phase(pmu_system_up)      ← mọi power domain lên
   io_update_voltage()           ← ★ VDDIO Quartz (MCP4542) — NGAY SAU khi domain lên
   write_ddr_memory_size()
   board_init(false)             ← iris/DDR/ATF
```

## 3 · Tóm tắt (theo format skill)

**1. Tồn tại để làm gì:** Máy có 3 rail điện áp lõi/IO, đặt ở 3 thời điểm khác nhau:
- **Quartz core VDD** — `avs_set_from_efuse(1097)` trong `main()` giai đoạn 4 → thực chất
  `avs_millivolts_set(1097)`: tra mã (dải 0.747–1.342 V), ghi `AVS_VDDLIMIT` (high==low) tại
  `0xE8244008`, bật `AVS_CONTROL.ENABLE|RST_B` tại `0xE8244000`. **Đường hiệu chỉnh theo efuse
  bị `#if 0`** — chỉ log mã, luôn đặt 1097 mV.
- **A72 core VDD** — `ap806_update_voltage()` trong `pmu_ap_link_up` (dùng efuse thật `0xCE6F9000`).
- **VDDIO Quartz** — `io_update_voltage()` trong `init_thread` sau `pmu_system_up`: qua chiết áp
  số **MCP4542** (I2C1 `0x2D`), `wiper_code = (12000250 − 10000·mV)/15750` (nghịch đảo), clamp
  1000–1200 mV, mặc định 1100.

**2. Call flow:**
```
main() gđ 4:
  pmu_phase(pmu_baseline)
  avs_set_from_efuse(1097) [hal_main.c:717]
     → (efuse valid?) đọc+log avs_low/high (bit 81/87), #if 0 avs_set_high_low
     → avs_millivolts_set(1097) [avs.c:194]
          → lookup_AVS_Volt_Code(1097) → mã
          → avs_set_high_low(mã, mã) [avs.c:167]
               → RMW 0xE8244008 (VDDLIMIT high+low) ; RMW 0xE8244000 (CONTROL ENABLE|RST_B)
          → cpu_spin_delay(5ms)

init_thread [hal_main.c:187]:
  (sau pmu_phase(pmu_system_up))
  io_update_voltage() [hal_main.c:989]
     → [IO_VOLT_PROMPT_DURATION_MS>0] prompt_for_desired_io_voltage(1100)  (UART, dev)
     → io_millivolts_set(millivolts) [hal_main.c:773]
          → [!IC_ENABLE_STATUS] MCP4542_i2c_configure()  (I2C1 0x2D, IC_CON=0x63)
          → clamp 1000..1200
          → wiper_code = (12000250 - 10000*mV) / 15750
          → IC_DATA_CMD: [0x00 cmd] [wiper_code | STOP]
          → cpu_spin_delay(1ms)
     → setI2CINA219Cfg(...) ×N  (cảm biến dòng)
```

**4. Đã xác nhận / phát hiện:**
- 🔴 `avs_set_from_efuse(1097)` **KHÔNG dùng efuse để đặt điện áp** — đường `avs_set_high_low(avs_low,
  avs_high)` bị `#if 0`, luôn `avs_millivolts_set(1097)`. Chỉ đọc+in mã efuse để log.
- ✅ AVS Quartz: `0xE8244000` (CONTROL ENABLE|RST_B), `0xE8244008` (VDDLIMIT high==low), efuse mirror
  `0xE8002080` (VALID bit 113, low bit 81, high bit 87, mã 6-bit). Dải 0.747–1.342 V.
- ✅ `avs_set_high_low` đặt high == low ⇒ khoá điện áp một mức (không cho AVS dao động).
- ✅ MCP4542: I2C1 `0x2D`, `CMD_SET_WIPER = 0x00`, `wiper_code = (12000250 − 10000·mV)/15750`
  (nghịch đảo: mV cao → code thấp), 7-bit 0..127, clamp 1000–1200 mV, mặc định 1100.
- ✅ `io_update_voltage` gọi trong `init_thread` **ngay sau `pmu_system_up`**, trước `board_init`.
- ✅ 3 rail đặt ở 3 nơi: Quartz VDD (`main` gđ 4), A72 VDD (`pmu_ap_link_up`), VDDIO (`init_thread`).
- ✅ `DATA_CMD_DATA` trong `hal_main.c` dùng `DAT_SHIFT` (đúng), khác bug `i2c_regmasks.h` (`Core/I2C.md §3.7`).
- ✅ `prompt_for_desired_io_voltage` (UART tương tác qua AP806 MPP 11/19) — chỉ bring-up.
