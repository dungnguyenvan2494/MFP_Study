## 1 · `AppInit_Initialize()` (`app_init.c:99-113`)

```c
const uint8_t set_speed[] = "\x00=set_speed";
void AppInit_Initialize(void) {
    SYS_INIT_CFG *cfg = { SYS_INIT_USECASE_SDK };            // ① thực chất = NULL

    const volatile uint8_t *hook = &set_speed[0];            // ② công tắc tốc độ chip
    if (*hook == 4) SysApiSystem_set_speed(2);   // fast
    if (*hook == 2) SysApiSystem_set_speed(1);
    if (*hook == 1) SysApiSystem_set_speed(0);
    // comment: "if none of bit[0:2] is set no speed change happens"

    SysApiInit_Initialize(cfg);                              // ③ đi và không trở lại
}
```

### ① `cfg` = NULL, và use-case **chưa bao giờ được triển khai**
`sys_api_init.h:42-50`:
```c
typedef enum { SYS_INIT_USECASE_SDK=0, SYS_INIT_USECASE_ECMA, SYS_INIT_USECASE_MDNS } SYS_INIT_USECASE;
typedef struct _SYS_INIT_CFG { SYS_INIT_USECASE usecase; } SYS_INIT_CFG;
void SysApiInit_Initialize(SYS_INIT_CFG* Cfg);
```
`SYS_INIT_CFG *cfg = { SYS_INIT_USECASE_SDK }` khai báo một **con trỏ** khởi tạo bằng scalar `0`
→ `cfg == NULL`. `SysApiInit_Initialize(SYS_INIT_CFG* Cfg)` (`sys_init.c:76-108`) — **thân hàm
KHÔNG hề dùng `Cfg`**. Toàn bộ khái niệm SDK/ECMA/mDNS là stub. Nếu ai thêm `Cfg->usecase` →
dereference NULL ngay boot đầu.

### ② `set_speed` **chết hai lần** (xác nhận từ source)
- Byte đầu `\x00` → cả 3 `if` (`== 4/2/1`) đều không thoả.
- Kể cả khi vá byte: `SysApiSystem_set_speed(in)` (`sys_system_api.c:301`) →
  `HalApiChip_set_speed(in)` (`hal_chip.c:83`) — **thân hàm RỖNG** `{ }`.
  Comment: *"in=1 normal, in=2 highest ... best to call before scheduler starts"* — nhưng trên
  Quartz tốc độ chip đặt hoàn toàn ở `pmu_phase(pmu_baseline)` (`hwSetProcSpeed(SYS_BUS_CLOCK)`).
  Cơ chế `set_speed` là **di sản từ nền tảng Marvell khác**.

## 2 · `SysApiInit_Initialize()` (`sys_init.c:76-108`)

```c
void SysApiInit_Initialize(SYS_INIT_CFG* Cfg) {         // Cfg KHÔNG dùng
    HalApiMemory_RamInit();

    if (HalApiReset_WasCold()) {
        /* SRAM còn rác, mask log chưa hợp lệ → IM LẶNG TUYỆT ĐỐI */
    } else {
        /* warm start → in banner bằng mask của lần chạy trước */
        SysApiPrint_Write_varg("I", ..., "%s/%d %s %s (%s)\n", __func__, __LINE__,
                               __DATE__, __TIME__, Version_Info);
    }

    const volatile uint8_t dump_nvm[] = "0=dump_nvm";
    if (dump_nvm[0]=='1') HalApiMemory_dump_nvm();      // hook: bật dump NVM lúc boot

#ifdef OS_freertos
    SysApi_InitApplModules(NULL);                       // ← §3
    vTaskStartScheduler();                              // ★ scheduler chạy, KHÔNG return
#endif
    while (1);                                          // lưới an toàn (scheduler chết vì thiếu heap)
}
```

`HalApiReset_WasCold()` là cổng in log: **cold boot = im lặng** (rất khó debug nếu chết ở đây),
warm boot = in banner + `__DATE__ __TIME__` + `Version_Info`.

## 4 · `SysSystem_Init()` (`sys_system_init.c:81-131`)

```c
uint32_t SysSystem_Init(void** mem, uint32_t* memsize) {   // mem/memsize KHÔNG dùng
    // 1. Wake-on-link timer (chưa activate)
    WakeOnLinkTimer = SysApiTimer_Create(SYS_TIMER_FLAG_NO_ACTIVATE, {
        .func = HalApiWol_EnableWakeOnLink, .initial_ticks = 600, .reschedule = false });

    SysSystem_HostMsgInit();

    // 2. Năm mutex
    SysSystem_MutexSystem  = SysApiThread_MutexCreate("MutexSystem");
    SysSystem_MutexApiApp  = SysApiThread_MutexCreate("MutexApiApp");
    SysSystem_MutexSockApi = SysApiThread_MutexCreate("MutexSockApi");
    SysSystem_MutexApiSys  = SysApiThread_MutexCreate("MutexApiSys");
    SysSystem_MutexHostApp = SysApiThread_MutexCreate("MutexHostSys");

    // 3. Hai event group
    SysSystem_AppEventGroup = SysApiThread_EventFlagsCreate("EventGroupApp");
    SysSystem_SysEventGroup = SysApiThread_EventFlagsCreate("EventGroupSys");   // ← wake_system dùng

    // 4. Tạo task chính của tầng System
    Info = { .func = SysSystem_ThreadMain, .name = "SysT", .stacksize = SYSTEM_STACK_SIZE };
    task_handle = SysApiThread_Create(SYS_THREAD_FLAG_AUTO_START, &Info);      // prio 1
    if (!task_handle) while(1);   // "dont know what to do when the main thread does not run"
    return 0;
}
```

⚠ **Comment sai (di sản ThreadX):** *"currently we rely on that following thread is created
first, which means this thread will be executed first after threadx initialization... the isr
handler will be activated in that thread."*
Dưới FreeRTOS **KHÔNG đúng**: `SysSystem_ThreadMain` prio 1, còn `init_thread` prio 3 (tạo sau,
ở `power_up_system()`) → **`init_thread` chạy trước**. ISR tick được bật ở cuối `SysApi_InitApplModules`
(bước 14), không phải trong `SysSystem_ThreadMain`.

## 6 · `SysSystem_ThreadMain` → `AppInit_StartThreads` (`sys_system_thread.c:110-148`)

```c
void SysSystem_ThreadMain(uint32_t thread_input) {
    HalApiReset_WasCold() ? "COLD START" : "WARM START (%u)";
    HalApiInit_general();
    SysApiFifo_Init();                              // host command FIFO (HCI) — T6
    if (!HalApiInit_DriverIsPresent())
        HalApiWol_SDKPatternEnable();               // dựng hardware pattern khi driver Linux CHƯA có
    HalApiIsr_Register(true, false, HAL_ISR_TYPE_HCU, SysSystem_HcuIsr);
    HalApiIsr_Unmask(false, HAL_ISR_TYPE_HCU);      // bật ngắt HCU
    start_sample_server();                          // no-op (không macro test nào define)

    AppInit_StartThreads();                         // ★ tạo AppThread_Main

    while (1) {                                     // vòng lặp dispatch — SysSystem_ThreadMain.md
        if (HalApiInit_DriverIsPresent()) SysSystem_System_EventsGet(&Events);   // poll không block
        else SysApiThread_EventFlagsGet(SysSystem_SysEventGroup, OR_CLEAR, &Events,
                                        SYS_EVENT_ALL, EVENT_GET_WAIT_FOREVER);   // block vô hạn
        SysSystem_handle_link_events(Events);
        SysSystem_periodic_debug_prints();
        SysHostcmd_HandlePendingCmds();
        SysFifo_HandlePendingRequests();
    }
}
```

## 7 · Cơ chế priority — tất cả gom về 3 mức

`SysApiThread_Create` (`sys_thread_api.c:91-126`): `SYS_THREAD_INFO` **không có trường priority**.
Mọi thread tầng Sys/App tạo qua đây đều dùng cứng:
```c
#define TASK_DEFAULT_PRIORITY  (configMAX_PRIORITIES - 3)   // = 4 - 3 = 1
xTaskCreate(func, name, stacksize/4, NULL, TASK_DEFAULT_PRIORITY, &xCreatedTask);
```

### Thang priority (configMAX_PRIORITIES = 4)

| Prio | Task | Tạo bởi | Thời điểm | Đặc điểm |
|---|---|---|---|---|
| **3** | `init thread` | `power_up_system()` — `xTaskCreate(..., configMAX_PRIORITIES-1)` | trước scheduler | chạy 1 mạch → `vTaskDelete(NULL)` |
| **3** | `Tmr Svc` (timer daemon) | FreeRTOS — `configTIMER_TASK_PRIORITY = configMAX_PRIORITIES-1` | tại `vTaskStartScheduler` | phục vụ `xTimerPendFunctionCall` (wake_system) |
| **1** | `SysT` (`SysSystem_ThreadMain`) | `SysSystem_Init()` — `SysApiThread_Create` AUTO_START | trước scheduler | consumer `SysEventGroup`, tạo AppMvl |
| **1** | `AppMvl` (`AppThread_Main`) | `AppInit_StartThreads()` — DONT_START + Resume | sau scheduler (do SysT gọi) | tạo 5 task KM, chạy `ApiAppMainLoop` |
| **0** | `MHU` (AppMhuTest) | `AppThread_Main` — `xTaskCreate` `tskIDLE_PRIORITY` | sau AppMvl | SCPI gateway |
| **0** | `cmd thread` | như trên | | console UART |
| **0** | `PwEvtMgr` | như trên | | state machine nguồn |
| **0** | `PwMHUEv` | như trên | | SCPI → internal event |
| **0** | `ClrWDT` (stack 200 words) | như trên | | 2 watchdog |
| **0** | `IDLE` | FreeRTOS | tại scheduler start | + `vApplicationIdleHook` |

### Trình tự thực thi sau `vTaskStartScheduler()`
```
1. init thread (prio 3)         chạy hết pha 2 (LPPP_KM_Init → pmu_phase → board_init → QoS)
                                 → event_handler(PWR_SW_ON) → pwr_sd = NORMAL
                                 → vTaskDelete(NULL)
2. Tmr Svc (prio 3)             idle, chờ timer command queue
3. SysT / SysSystem_ThreadMain  HalApiInit_general, SysApiFifo_Init, bật ngắt HCU
   (prio 1)                     → AppInit_StartThreads() → tạo + Resume AppMvl
4. AppMvl / AppThread_Main      MHU_init, ApiAppInit, TimerInit
   (prio 1)                     → tạo 5 task KM (prio 0)
                                → vòng lặp ApiAppMainLoop()
5. các task KM (prio 0)         round-robin: AppMhuTest, PwEvtMgr, PwMHUEv, ClrWDT, cmd_thread
```

Chênh lệch priority này bảo đảm: `LPPP_KM_Init()` (tạo 3 queue) trong `init_thread` **luôn xong
trước** khi bất kỳ task prio 0/1 nào gọi `xQueueReceive` — không có race dù không có đồng bộ tường minh.

## 8 · Cấu hình (`Makefile-lib-cfg:56-60`, truyền qua `-D`)

```make
SYSTEM_HEAP_SIZE  := "(23*1024)"    # 23 KB cố định (cũ: 19 KB — #SYSTEM_HEAP_SIZE := "(19*1024)")
```

last APP_HEAP_SIZE big"*. `pvPortMalloc` của FreeRTOS → heap SYSTEM (23KB) → TCB/stack/queue/
semaphore của kernel đều ăn vào đó (lý do nâng 19→23 KB).

## 9 · Tóm tắt (theo format skill)

**1. Tồn tại để làm gì:** `AppInit_Initialize` là cửa vào tầng ứng dụng — `main()` của HAL trao
quyền tại đây. Nó (a) chọn use-case SDK (thực chất NULL, chưa triển khai), (b) chạy công tắc
`set_speed` (chết 2 lần), rồi (c) gọi `SysApiInit_Initialize` → `SysApi_InitApplModules` (dựng
2 heap, mạng, wake source, tạo `SysSystem_ThreadMain` prio 1 + `init_thread` prio 3, bật tick)
→ `vTaskStartScheduler()` (không return).

**2. Call flow + priority:** xem §7. 3 mức: prio 3 (`init thread` transient + `Tmr Svc`),
prio 1 (`SysT`, `AppMvl`), prio 0 (5 task KM + IDLE). `SysApiThread_Create` gán cứng
`TASK_DEFAULT_PRIORITY = configMAX_PRIORITIES-3 = 1`.

**3. File đã tham chiếu:**
- `ApplicationMrvl/init/app_init.c:99-217`
- `Sys/init/sys_init.c:76-207`
- `Sys/init/sys_api_init.h:42-58`
- `Sys/system/sys_system_init.c:81-131`
- `Sys/system/sys_system_thread.c:110-165`
- `Sys/thread/sys_thread_api.c:57-126`
- `Sys/system/sys_system_api.c:301`
- `Hal/quartz/src/hal_chip.c:78-84`

- `Makefile-lib-cfg:54-60, 245-248`

**4. Đã xác nhận:**
- ✅ `SysApiInit_Initialize(Cfg)` **không dùng `Cfg`** — use-case SDK/ECMA/mDNS là stub.
- ✅ `HalApiChip_set_speed()` **rỗng** trên Quartz.
- ✅ Comment "SysSystem_ThreadMain chạy đầu tiên" trong `SysSystem_Init` là **di sản ThreadX SAI** —
  `init_thread` prio 3 chạy trước.
- ✅ `lpp_usbd_init` + `wake_pcie_init` **luôn build** (`#if 1`); `USB_DEVICE`/`DASH`/`ARCH_8080` KHÔNG.
