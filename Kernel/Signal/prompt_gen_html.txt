============================================================
# COMMON MISCONCEPTIONS
============================================================

Ví dụ:

❌ Signal generation = signal delivery

❌ Signal blocked means signal disappears

❌ kill() always immediately executes handler

❌ signal handler runs in kernel mode

❌ sigreturn simply returns like normal function

❌ all signals are queued individually

Mỗi item:

    WRONG
    CORRECT
    WHY
    SOURCE

Chỉ sử dụng misconception nếu source/research hỗ trợ.
