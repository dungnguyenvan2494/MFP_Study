## A. `get_board_type()` — bo mạch silicon (`board.c:72`)

### Enum `board_type_t` (`board.h:35`)
`PALLADIUM(0), PROTIUM(1), TOC(2), EMU800(3), ESEVAL(4), UNKNOWN(5)`

### Thuật toán
```c
#ifdef PALLADIUM  return BOARD_TYPE_PALLADIUM;   // (macro, không build cho S800)
if (cached != UNKNOWN)  return cached;
#if 0  // "Marvell đã bỏ chạm I2C" (T.Watanabe)
   if (i2c_search_one_device(AON_I2C0, 3, 0x50 /*EEPROM*/))  cached = TOC;
#else
   gpio_open(GPIO_BANKI, 31, INPUT); gpio_read(&level);
   level ? cached = ESEVAL : cached = EMU800;      // pin I[31] HIGH→ESEVAL, LOW→EMU800
   gpio_close();
#endif
return cached;
```
- **S800 production: pin BANK_I[31] = 0 → `BOARD_TYPE_EMU800`** (khớp T1.4).
- `ESEVAL` = ES eval board (`build_lppp.sh es` → `BOARD=s800es`).
- `TOC` / `PALLADIUM` / `PROTIUM` = emulator/FPGA (Palladium/Protium) — không dùng field.

| `default (UNKNOWN)` | — | `while(1)` (treo) |

### Rev silicon (không phải board)

## B. `supportTEC()` — thế hệ sản phẩm / Machine Type (`power.c:100`)

> "TEC" = có lẽ liên quan control PS-CPU thế hệ mới (Eagle3). Tên hàm = "hỗ trợ TEC?".

### Nguồn: EEPROM ảo trong QSPI flash
| define | offset (từ `SPI_BASEADDRESS = 0xF4000000`) | nội dung |
|--------|-------------------------------------------|----------|
| `DATA1_OFFSET` | `0x79000` | bản sao EEPROM #1 |
| `DATA2_OFFSET` | `0x7A000` | bản sao EEPROM #2 |
| `WRITE_COUNTER` | `+0x0000` | bộ đếm ghi (chọn bản mới hơn) |
| `MachineTypeOffset` | `+0x0054` | 2 byte Machine Type |

### Thuật toán
1. `flash_read` `WRITE_COUNTER` của cả 2 bản.
2. Chọn `dst`:
   - cả 2 lỗi → `RESULT_ERROR`.
   - 1 lỗi → dùng bản còn lại.
   - cả 2 OK → `count == 0xFFFFFFFF ? 0 : count`; chọn bản có `WRITE_COUNTER` lớn hơn (`count1 >= count2` → DATA1).
3. `flash_read(cMachine, dst + MachineTypeOffset, 2)`. `g_cMachine = cMachine[0] + cMachine[1]*256`.
4. Tra `cMachine[0]` trong `stMachineTbl[]` → trả `u8result`; không thấy → `RESULT_NONE`.

### `stMachineTbl[]` (`power.c:116-132`)
| `cMachine[0]` | codename | → kết quả |
|---------------|----------|-----------|
| `0x10` `MACHINE_EAGLE` | Eagle | `RESULT_BASE` |
| `0x11` `MACHINE_SPARROW` | Sparrow | `RESULT_BASE` |
| `MACHINE_DENEBMLK` / `EAGLEBK` / `SPARROWBK` / `HELIOSMLK` / `MINERVASSBK` | | `RESULT_BASE` |
| `0x17` `MACHINE_EAGLE3` | Eagle Ⅲ | **`RESULT_EAGLE3`** |
| `MACHINE_SPARROW3` / `EAGLEBK3` / `SPARROWBK3` / `SPARROWH` / `EAGLE3MLK` / `EAGLEBK3MLK` / `SPARROW3MLK` / `SPARROWBK3MLK` / `0x22 SPARROWHMLK` | Ⅲ generation | **`RESULT_EAGLE3`** |

### Kết quả (`power.c:66-69`)
`RESULT_NONE=0` (không rõ), `RESULT_BASE=1` (Eagle Ⅰ/Ⅱ, Sparrow Ⅰ/Ⅱ…), `RESULT_EAGLE3=2` (thế hệ Ⅲ), `RESULT_ERROR=-1`.

> ⚠️ "S800"/"bizhub" **không** xuất hiện trực tiếp trong bảng — S800 là 1 trong các codename này (Eagle/Sparrow…). `build_lppp.sh` có riêng `es`(s800es)/`emu`(s800emu) nhưng đó là **board silicon**, không phải Machine Type.

### Dùng ở đâu — nhánh **Eagle3-only**
| nơi | Eagle3 làm gì thêm |
|-----|---------------------|
| `ap806_power_on(on=true)` `power.c:327` | trước `AP_PWR_EN=1`: nếu `isAutomaticMeasurementToolOn()` → `LPPP_i2c_write(PSCPU, 0xC0, THRD_EventRecord_ResumeRequest)`; **`send_sleep_status_rem(1)`** (I²C `0x3E:0x6C ← 0x0001`) → chờ 100ms → mới `AP_PWR_EN=1` |
| `ap806_power_on(on=false)` `power.c:392` | sau `AP_PWR_EN=0`: chờ 100ms → **`send_sleep_status_rem(0)`** |
| `send_power_state_to_pscpu(on)` `LPPP_I2C.c:1029` | `gen = 0x04` OR vào lệnh I²C `0x3E:0x68` (khớp T4.2: `\|0x04` Eagle3). Boot=`0x02\|gen`, Normal=`0x00\|gen`, Sleep2/ErP=`0x01\|gen` |
| `hal_main.c:177` | `if (supportTEC() != RESULT_BASE) { ... }` — hành động cho non-BASE (Eagle3/None) |

⇒ Khác biệt runtime chính giữa **BASE** và **EAGLE3**: chuỗi bắt tay **REM (sleep-status-remote)** với PS-CPU qua I²C `0x6C` và cờ `gen |= 0x04` trong lệnh `0x68` — Eagle3 PS-CPU cần biết trạng thái remote power/sleep, thế hệ cũ không.

## C. FW_CONFIG pin (282-287) — **không dùng**

`LPPP_Gpio.c:58`: comment *"FW_CONFIG[0:3] 未使用のためInputの設定は行わない"* = "FW_CONFIG[0:3] không dùng nên không cấu hình input". `FW_CONFIG0..5` có trong `gpio_info[]` (input, rising-edge) nhưng chỉ `gpio_open` rồi `gpio_close` (T7.2) — LPPP **không đọc** giá trị. Dự phòng cho cấu hình firmware qua strap pin, chưa kích hoạt.

`CH0/CH1_DDR_VENDOR1/2` (278-281) + `DDR_CONFIG` (217): output, `write_ddr_memory_size()` ghi ra để U-Boot đọc kích thước/hãng LPDDR4 (T8.1). `LPPP_GPIO_WatchPort` không theo dõi các pin này.

## D. FACT / INFERENCE / UNKNOWN

- **FACT**: `get_board_type` = `#ifdef PALLADIUM` → PALLADIUM; else GPIO BANK_I[31]: 1=ESEVAL, 0=EMU800; I²C-EEPROM-TOC path `#if 0`; cached; `board_init`/`early_board_init`/`init_ddr`/`ap806_power_on` phân nhánh theo nó (EMU800 = S800 production).
- **FACT**: `supportTEC` đọc 2-byte Machine Type từ QSPI `0x79000`/`0x7A000` + `0x54` (chọn bản `WRITE_COUNTER` mới hơn); `stMachineTbl[]` map codename → `RESULT_BASE`(1) / `RESULT_EAGLE3`(2); `RESULT_NONE`(0), `RESULT_ERROR`(-1); Eagle3 thêm `send_sleep_status_rem` + `gen |= 0x04`.
- **FACT**: `get_quartz_rev` = APB_CONFIG+0x40 >>28; `get_iris_rev` = SB_IRIS0+0xA8 >>16 &0xF; FW_CONFIG pins không đọc.
- **INFERENCE**: S800 (bizhub) = một trong các codename Eagle/Sparrow. Vì `send_power_state_to_pscpu` mặc định `gen=0` (BASE) trừ khi Eagle3, và note trước (T4.2) nói "Eagle3 |0x04", S800 có thể là BASE **hoặc** Eagle3 tuỳ đời máy — Machine Type đọc từ flash lúc chạy, không cố định trong FW. Chưa xác định S800 map vào codename nào.
- **INFERENCE**: `PALLADIUM`/`PROTIUM`/`TOC` không liên quan sản phẩm (emulator/FPGA). Chỉ EMU800 (và ESEVAL cho ES board) dùng thực.
- **UNKNOWN**: giá trị `cMachine[0]` thực của máy S800 (ghi ở nhà máy vào flash). `MACHINE_*` codename ↔ tên thương mại Konica Minolta. `isAutomaticMeasurementToolOn()` (đo tự động — production test?). `TEC` viết tắt của gì.
- **UNKNOWN**: `hal_main.c:177` `if (supportTEC() != RESULT_BASE)` làm gì cụ thể (chưa đọc thân).
- **UNKNOWN**: FW_CONFIG dự tính điều khiển gì (biến thể firmware theo strap?).

## Tóm tắt (theo format skill)

**Hai trục "type":** (A) `get_board_type()` phát hiện **bo silicon** bằng GPIO BANK_I[31] (0 → `EMU800` = S800 production, 1 → `ESEVAL`; các loại emulator qua macro/`#if 0`), cached, dùng để chọn nhánh `board_init_*` / `init_ddr` / `ap806_power_on` cho HW. (B) `supportTEC()` phát hiện **thế hệ sản phẩm** bằng 2-byte Machine Type đọc từ EEPROM-ảo trong QSPI flash (`0x79000`/`0x7A000` + `0x54`, chọn bản `WRITE_COUNTER` mới hơn), tra `stMachineTbl[]` ra `RESULT_BASE` (Eagle/Sparrow Ⅰ/Ⅱ) hoặc `RESULT_EAGLE3` (thế hệ Ⅲ). Khác biệt runtime BASE↔EAGLE3 nằm ở bắt tay nguồn với PS-CPU: Eagle3 gửi thêm `send_sleep_status_rem()` (I²C `0x3E:0x6C`) quanh `AP_PWR_EN` và OR `gen |= 0x04` vào lệnh power `0x3E:0x68`. FW_CONFIG strap pin (282-287) tồn tại nhưng LPPP không đọc.
