1. Watermark cho 1 zone, managed = 250000 page (~977 MiB)
======================================================================
min_free_kbytes = 4000 KiB  -> pages_min = 1000
tmp = max(min>>2=250, managed*10/10000=250) = 250
WMARK_MIN  =   1000 page = 3.91 MiB
WMARK_LOW  =   1250 page = 4.88 MiB
WMARK_HIGH =   1500 page = 5.86 MiB
=> free < LOW  : allocator danh thuc kswapd (wakeup_kswapd)
=> free > HIGH : kswapd ngu lai (pgdat_balanced)
=> free < MIN  : chi con ALLOC_HARDER/ALLOC_HIGH/PF_MEMALLOC duoc cap tiep; con lai vao direct reclaim
kswapd_shrink_node: nr_to_reclaim = max(high, 32) = 1500 page (~5.9 MiB moi lan shrink_node)
max watermark boost = high * 15000/10000 = 2250 page  (boost_watermark)

9. vmpressure window
======================================================================

  scanned=512 reclaimed=400 ->  21% -> low
  scanned=512 reclaimed=200 ->  60% -> medium
  scanned=512 reclaimed= 20 ->  96% -> critical
  scanned=512 reclaimed=  0 -> 100% -> critical
