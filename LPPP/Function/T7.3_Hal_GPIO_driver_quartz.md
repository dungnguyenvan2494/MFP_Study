**FACT.** 9 bank A–I, mỗi bank 1 block thanh ghi cách nhau `0x100`:

| bank | enum | base | số pin | global pin = bank×32 + index |
|------|------|------|--------|------------------------------|
| A | `GPIO_BANKA=0` | `0xE830A000` | 32 | 0–31 |
| B | 1 | `0xE830A100` | 32 | 32–63 |
| C | 2 | `0xE830A200` | **16** | 64–79 |
| D | 3 | `0xE830A300` | 32 | 96–127 |
| E | 4 | `0xE830A400` | 32 | 128–159 |
| F | 5 | `0xE830A500` | 32 | 160–191 |
| G | 6 | `0xE830A600` | 32 | 192–223 |
| H | 7 | `0xE830A700` | 32 | 224–255 |
| I | 8 | `0xE830A800` | 32 | 256–287 |

`gpio_base_addrs[9]`, `gpio_num_pins[9] = {32,32,16,32,32,32,32,32,32}`. `NUM_GPIO_PINS_PER_GRP = 32`. → khớp chính xác pin number trong `LPPP_Gpio.h` (T7.2: pin 62 = BANK B idx 30, pin 66 = BANK C idx 2, pin 224 = BANK H idx 0…).

### 1.1 `struct GPIO0_REGS_t` (offset trong block)

| off | reg | R/W | ý nghĩa |
|-----|-----|-----|---------|
| 0x00 | `PLR` | R | **Pin Level** (mức vật lý hiện tại) |
| 0x04 | `PDR` | R/W | Pin Direction (1=out) |
| 0x08 | `PSR` | W | Output **Set** (ghi 1 → pin HIGH) |
| 0x0C | `PCR` | W | Output **Clear** (ghi 1 → pin LOW) |
| 0x10 | `HRIPR` | R/W | High/Rising Interrupt Polarity |
| 0x14 | `LFIPR` | R/W | Low/Falling Interrupt Polarity |
| 0x18 | `ISR` | R/W1C | Interrupt **Status** |
| 0x1C | `SDR` | W | Direction **Set** (→ output) |
| 0x20 | `CDR` | W | Direction **Clear** (→ input) |
| 0x24 | `SHRIPR` | W | bitwise **set** High/Rising-edge detect enable |
| 0x28 | `CHRIPR` | W | bitwise **clear** High/Rising-edge detect enable |
| 0x2C | `SLFIPR` | W | bitwise **set** Low-level/Falling-edge detect enable |
| 0x30 | `CLFIPR` | W | bitwise **clear** Low/Falling-edge detect enable |
| 0x34 | `OLR` | – | Output Level Register |
| 0x38 | `DWER` | – | Direct-Write Enable |
| 0x3C | `IMR` | R/W | Interrupt **Mode** (0=edge, 1=level) |
| 0x48 | `SIMR` | W | bitwise **set** IMR (→ level mode) |
| 0x4C | `CIMR` | W | bitwise **clear** IMR (→ edge mode) |
| 0x50–0x5C | `ITER0..3` | R/W | **Interrupt Enable cho 4 Interrupt Target** (mask per pin) |

### 1.2 4 Interrupt Target — `ITER0..3`
Comment HW: *"ITERn = Interrupt Enable Register for Interrupt bit x where x%4 == n, going to Interrupt Target (x−(x%4))/4"*. Thực tế driver dùng nó như **4 đích ngắt độc lập**, mỗi bank có 4 dòng SPI: `interrupt_number[bank][4] = {INTNUM_GPIO_x_0..3}` (bank A: SPI 109–112, bank B: 113–116…).

| ITER index | đích | ai dùng |
|------------|------|---------|
| 0, 1 | (target 0/1) | không dùng trong FW này |
| **2** | `GPIO_INT_DEST = 2` | **R4 / LPPP** — `gpio_init` attach `gpio_internal_isr` vào `INTNUM_GPIO_x_2` |
| **3** | target 3 | **AP (Linux/ATF)** — `LPPP_GPIO_CallbackMainSW` kiểm `gpio_get_itern(bank,3)` để biết "AP đang bật ngắt này" |

⇒ Cùng một pin có thể route ngắt tới **cả R4 (ITER2) và AP (ITER3)** độc lập. LPPP nhường quyền xử lý cho AP nếu `ITER3` bật (T7.2 §5).

## 2. `gpio_init()` (`hal_gpio.c:214-258`) — gọi 1 lần lúc bring-up HAL

Cho mỗi bank:
1. Khởi tạo 32 `pin_handle_t` trong `pin_handle_list[9][32]`: `is_open=false`, `cookie=GPIO_INTERNAL_HANDLE_COOKIE`, `index=pin_index`, `isr_callback=NULL`, `logic_setting=ACTIVE_HIGH`, `regs=<base bank>`.
2. Tắt phát hiện cạnh: `CHRIPR = -1; CLFIPR = -1; IMR = 0` (clear all).
3. `intAttach(INTNUM_GPIO_x_2, 0, gpio_internal_isr, group_index)` + `intEnable(...)` — 1 handler dùng chung cho cả bank, tham số = số bank.

`struct gpio_handle_s`: `cookie` (validate handle từ ngoài), `global_pin_num`, `regs`, `is_open`, `logic_setting`, `isr_type`, `index`, `isr_callback`, `isr_callback_data`.

## 3. API cơ bản

### `gpio_open(**handle, bank, pin_num, dir, logic_setting, logic_level)` (`:263-334`)
- `pin = &pin_handle_list[bank][pin_num]`, kiểm `cookie`, kiểm `is_open` (đã mở → `FAIL`).
- Nếu OUTPUT → `gpio_internal_pin_output_set(pin, logic_level)` (drive trước).
- `gpio_internal_pin_direction_set(pin, dir)` → ghi `SDR` (out) / `CDR` (in), "zeros are ignored" (bitwise).
- Clear edge-detect + `ITER2` bit của pin: `SHRIPR &= ~b; CLFIPR &= ~b; ITER2 &= ~b`.
- `is_open = true`, `*handle = pin`.

### `gpio_write(pin, logic_level)` → `gpio_internal_pin_output_set` (`:731-750`)
```c
if ((logic_level ^ pin->logic_setting) & 0x1)   pin->regs->PSR = (1<<index);  // HIGH
else                                            pin->regs->PCR = (1<<index);  // LOW
temp = pin->regs->PLR;   // "must read to make set work"  — dummy read chốt ghi
```
`logic_setting == ACTIVE_LOW (1)` ⇒ đảo: logic 1 → PCR (LOW vật lý). Đây là chỗ trừu tượng hoá "logic level" khỏi "physical voltage" (bảng trong `gpio_api.h`).

### `gpio_read(pin, *logic_level)` → `gpio_internal_pin_input_get` (`:641-660`, không đọc thân đầy đủ)
Đọc `PLR & (1<<index)`, áp `logic_setting`, trả 0/1.

### `gpio_set_direction` → `gpio_internal_pin_direction_set` (SDR/CDR).

### `gpio_close(pin)` — đặt `is_open=false`, giải phóng handle.

## 4. API ngắt — 3 mức: attach → setup/enable

| hàm | làm gì | ITER2 (unmask R4)? |
|-----|--------|---------------------|
| `gpio_isr_attach(pin, cb, data, type)` (`:433-468`) | lưu `isr_callback`/`isr_callback_data`/`isr_type`; ép direction = INPUT. **KHÔNG** đụng thanh ghi ngắt | ❌ |
| `gpio_isr_setup(pin)` (`:609-628`) | chỉ `gpio_internal_pin_interrupt_polarity_set(pin, isr_type)` — cấu hình HRIPR/LFIPR/IMR để **HW phát hiện** cạnh/mức | ❌ (vẫn masked) |
| `gpio_isr_enable(pin)` (`:497-518`) | `polarity_set(...)` **+ `ITER2 |= (1<<index)`** (unmask → R4 nhận ngắt) | ✅ |
| `gpio_isr_disable(pin)` (`:520-540`) | `ITER2 &= ~(1<<index)` + `polarity_clear` (SHRIPR/CLFIPR write) | — |
| `gpio_isr_detach(pin)` (`:471-495`) | ASSERT `APMASK` sạch, xoá callback | — |
| `gpio_isr_ack(pin)` | no-op (return OK) | — |

### 🔑 `setup` vs `enable` — giải thích T7.2
- `gpio_info[]` (POWER_MONITOR 48, XEN_LVDS_ENG 224): `attach` + **`enable`** → ITER2 bật → `gpio_internal_isr` gọi `LPPP_GPIO_Callback`.
- `wake_gpio_info[]` (14 pin wake): `attach(CallbackDummy)` + **`setup`** (không enable) → HW phát hiện cạnh/mức để **đánh thức domain nguồn** nhưng **R4 KHÔNG nhận ngắt phần mềm** (ITER2 masked). Callback dummy không bao giờ chạy.

### 4.1 `gpio_internal_pin_interrupt_polarity_set(pin, isr_type)` (`:752-786`)

| isr_type | ghi |
|----------|-----|
| `FALLING_EDGE` | `CIMR=b` (edge mode) ; `CHRIPR=b` ; `SLFIPR=b` (bật phát hiện falling) |
| `RISING_EDGE` | `CIMR=b` ; `SHRIPR=b` ; `CLFIPR=b` |
| `EITHER_EDGE` | `CIMR=b` ; `SHRIPR=b` ; `SLFIPR=b` (bật cả 2) |
| `LEVEL_LOW` | `SIMR=b` (level mode) ; `CHRIPR=b` ; `SLFIPR=b` |
| `LEVEL_HIGH` | `SIMR=b` ; `SHRIPR=b` ; `CLFIPR=b` |

`polarity_clear`: `SHRIPR=b ; CLFIPR=b` (chỉ clear rising+falling detect enable).

## 5. `gpio_internal_isr(group_index)` (`:662-708`) — ISR dùng chung 1 bank

```c
curr = gpio_base_addrs[group_index];
current = original = curr->ISR & curr->ITER2;          // chỉ pin đã unmask cho R4
while ((pin_index = ffs(current)) != 0) {
    pin_index--;
    pin = &pin_handle_list[group_index][pin_index];
    if (pin->is_open && pin->isr_callback) {
        gpio_internal_pin_input_get(pin, &logic_level);
        if (pin->isr_callback(pin, logic_level, pin->isr_callback_data))
            original &= ~(1 << pin_index);             // callback trả TRUE → KHÔNG ack (giữ pending)
    }
    current &= ~(1 << pin_index);
}
curr->ISR = original;                                   // W1C: ack các pin callback trả FALSE
```
- `ffs()` duyệt từng bit set.
- **Return value của callback**: `true` = "đừng clear ngắt" (dùng cho suspend/resume — giữ pending để wake); `false` = clear (ack).
  → Các callback LPPP (`LPPP_GPIO_Callback`, `LPPP_GPIO_CallbackMainSW`, `CallbackDummy`) đều return **false** ⇒ luôn được ack ngay.

## 6. `gpio_get_itern` / `gpio_set_itern` (`:562-607`)

```c
uint32_t gpio_get_itern(uint32_t block, uint32_t index) {   // index 0..3
    if (index > 3) return 0;
    curr = gpio_base_addrs[block];
    return *(((uint32_t*)&curr->ITER0) + index);            // đọc ITER<index>
}
void gpio_set_itern(uint32_t block, uint32_t index, uint32_t mask) {
    if (index > 3 || block > 9) return;
    *(((uint32_t*)&curr->ITER0) + index) = mask;            // ghi cả thanh ghi
}
```
`gpio_get_val(blk, offset)` = đọc thô `*(base[blk] + offset)`.

**Dùng ở đâu:** `LPPP_GPIO_CallbackMainSW` (T7.2 §5): `gpio_get_itern(bank(62)=1, 3)` → nếu bit 30 (idx của pin 62) set trong `ITER3` (target AP) ⇒ AP đang bật ngắt MainSW ⇒ LPPP không tự tắt nguồn. Ngược lại (AP không bật) LPPP kéo `HRESET_REQN=0`.

## 8. FACT / INFERENCE / UNKNOWN

- **FACT**: 9 bank, base `0xE830A000`+`0x100`×n, bank C 16 pin, `GPIO0_REGS_t` layout, `gpio_init` (init handles + disable edge + attach `gpio_internal_isr` vào `INTNUM_GPIO_x_2`), `gpio_open/write/read/set_direction`, 3 mức ngắt attach/setup/enable, `polarity_set` bảng, `gpio_internal_isr` (ISR&ITER2, ffs loop, callback-true = giữ pending), `gpio_get_itern`/`set_itern`, dummy read PLR.
- **FACT**: ITER2 = đích R4, ITER3 = đích AP (từ `GPIO_INT_DEST=2` + cách `LPPP_GPIO_CallbackMainSW` đọc ITER3).
- **INFERENCE**: `wake_gpio_info` pins chỉ `setup` (polarity, không ITER2) ⇒ phục vụ HW wake domain chứ không sinh ISR R4 — khớp T7.2. Chưa trace tín hiệu GPIO edge/level tới PMU/GIC wake logic (T9).
- **INFERENCE**: `pin->regs->GPIO_CDR` / `GPIO_SDR` trong `gpio_internal_pin_direction_set` là macro alias của `CDR`/`SDR` (struct chỉ có `CDR`/`SDR`). Chưa mở file macro.
- **INFERENCE**: 4 target ITER tương ứng {?, ?, R4, AP}. Target 0/1 có thể là M3 / secure. Không có bằng chứng trong FW này.
- **UNKNOWN**: `gpio_internal_pin_input_get` thân đầy đủ (giả định PLR & mask + logic_setting). `INTRL_GIC_OFFSET` giá trị (để ra SPI thật của `INTNUM_GPIO_A_2` = 111 + offset).
- **UNKNOWN**: `OLR`/`DWER` (Output Level / Direct-Write Enable) — driver không dùng; vai trò với chế độ direct-write chưa rõ.
- **UNKNOWN**: quan hệ giữa bank GPIO này (`0xE830Axxx`, tên "AP_GPIO") và pin controller PIOCFG dùng cho LVDS (`0xE8308440`, T3.4) — khác block.

## Tóm tắt (theo format skill)

**`hal_gpio.c` để làm gì:**
Driver GPIO chung của Marvell cho quartz: trừu tượng 9 bank × 32 pin (`0xE830A000`+) thành handle, tách "logic level" khỏi "physical voltage" qua `gpio_logic_setting_t`. Ghi ra pin bằng cặp set/clear register (`PSR`/`PCR`) + dummy-read `PLR`; đọc bằng `PLR`. Ngắt có 3 bước: `attach` (lưu callback, ép input) → `setup` (cấu hình HW phát hiện cạnh/mức: HRIPR/LFIPR/IMR) → `enable` (unmask `ITER2` để R4 thực sự nhận). Mỗi pin route ngắt độc lập tới 4 target qua `ITER0..3`; FW dùng **ITER2 cho R4**, và đọc **ITER3 để biết AP có đang giữ ngắt đó không**. ISR chung `gpio_internal_isr` quét `ISR & ITER2`, gọi callback; callback trả `true` để giữ pending (suspend/resume), `false` để ack (mọi callback LPPP trả false).

**Lifecycle 1 pin input có ISR (POWER_MONITOR 48):**
```
gpio_init()  → pin_handle_list[1][16] khởi tạo; INTNUM_GPIO_B_2 → gpio_internal_isr(bank=1)
LPPP_GPIO_Setting():
  gpio_open(&pin, BANKB, 16, INPUT, ACTIVE_HIGH, 0)
     → CDR=1<<16 (input); SHRIPR/CLFIPR/ITER2 clear bit 16; is_open=true
  gpio_isr_attach(pin, LPPP_GPIO_Callback, &pinno, EITHER_EDGE)
     → lưu callback; direction=INPUT
  gpio_isr_enable(pin)
     → polarity_set(EITHER): CIMR=b; SHRIPR=b; SLFIPR=b   (edge mode, cả 2 cạnh)
     → ITER2 |= 1<<16                                       (unmask cho R4)
--- runtime: điện chớp, pin 48 đổi mức ---
SPI INTNUM_GPIO_B_2 → gpio_internal_isr(1)
  status = ISR & ITER2 → bit16 set
  gpio_internal_pin_input_get(pin,&level)
  LPPP_GPIO_Callback(pin, level, &pinno)
     → LPPP_GPIO_AnalyzeEventfromISR → is_power_flicker(level) → PWR_FLICKER
     → xQueueSendFromISR(gst_MsgQHandle_PowerCtrl) ; return false
  ISR = original (ack bit16)
```
