## 2 · Data model (`sys_filter_main.c:64`)

```c
FilterProxyCfg  SysFilterStage[MAX_FILTER_STAGES /* = 2 */];   // [0]=STAGE_1, [1]=STAGE_2
```
Mỗi `FilterProxyCfg`:
- `pFilterList[MAX_FILTER_NUM]` — danh sách filter, mỗi filter có `FilterStatus` (FREE/USED/ENABLED),
  `ActionFlags`, `FilterFunctionID`, `ProtocolType`, và danh sách **sub-pattern**
- `Storage[MAX_STORAGE_BYTES]` — vùng byte chứa `value` + `mask` của mọi sub-pattern (offset tra qua
  `FilterStorageOffsetValueStorage(Id, spId)` / `...MaskStorage(...)`)

Mỗi **sub-pattern** = `{PatternOffset (trong gói), Length, value[], mask[]}`. Filter khớp ⟺
**tất cả** sub-pattern khớp: `for k in Length: (packet[off+k] & mask[k]) == (value[k] & mask[k])`.

## 3 · `SysFilter_Execute_Filter(packet, length, filterprot)` (`sys_filter_main.c:216-283`)

```c
Stage = filterprot ? SYS_FILTER_STAGE_2 : SYS_FILTER_STAGE_1;   // filterprot = L4 proto (0 = raw)
FilterIdx = SysFilter_PacketFilterGetMatchingFilterOfPacket(packet, length, filterprot);
   // duyệt SysFilterStage[Stage].pFilterList[]: chỉ filter có FILTER_ENABLED
   //   kiểm mọi sub-pattern (offset/value/mask/length, có bound-check vs length & MAX_STORAGE_BYTES)
   //   → trả Id (1-based, 0 = không khớp)

if (FilterIdx) {
    ActionFlags = SysFilter_PacketFilterGetActionFlagsOfFilter(FilterIdx, Stage);

    if (ActionFlags & FILTER_FLAG_FOR_APP_LAYER) {                 // ─ gửi lên tầng App
        if (APP_EVENT_RECEIVE_PM_PACKET & EventMask) {
            pData = SysApiMemory_Alloc(length); memcpy(pData, packet, length);
            SysFilter_PutPmPkt(pData, length, FilterIdx & FILTER_ID_MASK, filterprot);   // → PmPktQ (§5)
        }
    }
    if (Stage == STAGE_1  && (ActionFlags & FILTER_FLAG_FORWARD_PACKET))
        SysApiLan_PacketForwardToDriver(packet, length);           // ─ chuyển thẳng lên Linux (HCI FIFO)
#ifdef ENABLE_SECOND_FILTER_STAGE
    else if (ActionFlags & FILTER_FLAG_FORWARD_PACKET && saved_rawpacket)   // Stage 2 dùng saved_rawpacket (T5.1)
        SysApiLan_PacketForwardToDriver(saved_rawpacket->payload, saved_rawpacket->tot_len);
        pbuf_free(saved_rawpacket); saved_rawpacket = NULL;
#endif
    if (ActionFlags & FILTER_FLAG_WAKE_SYSTEM) {                   // ─ đánh thức host
        SysApiSystem_SetWakeReason(MvWakeReasonPacket);
        SysApiSystem_Wake();
        RedirectTraffic = true;                                    //   từ giờ mọi gói chuyển thẳng lên Linux
        SysApiThread_EventFlagsSet(SysSystem_SysEventGroup, _OR, SYS_EVENT_WAKE_SYSTEM);
    }
    if (ActionFlags & FILTER_FLAG_DISCARD_PACKET)
        return RC_DISCARD_PACKET;                                  // ─ KHÔNG cho gói vào lwIP
}
return RC_OK;                                                      // không khớp → gói tiếp tục vào lwIP
```

### 4 ActionFlag
| Flag | Hành động |
|---|---|
| `FILTER_FLAG_FOR_APP_LAYER` | copy gói → `PmPktQ` → `APP_EVENT_RECEIVE_PM_PACKET` |
| `FILTER_FLAG_FORWARD_PACKET` | `SysApiLan_PacketForwardToDriver` → HCI FIFO → Linux |
| `FILTER_FLAG_WAKE_SYSTEM` | `SysApiSystem_Wake()` + `RedirectTraffic = true` + `SYS_EVENT_WAKE_SYSTEM` |
| `FILTER_FLAG_DISCARD_PACKET` | `return RC_DISCARD_PACKET` (drop, không vào lwIP) |

Một filter có thể set nhiều flag cùng lúc (ví dụ `WAKE + FORWARD`: đánh thức host **và** chuyển gói lên).

## 5 · `PmPktQ` → `APP_EVENT_RECEIVE_PM_PACKET` → `AppThread_HandlePatternMatchedPacket`

```
SysFilter_PutPmPkt (sys_filter_main.c:288):
   mutex ; PmPktQ.pkt[WrIdx] = {pPacket (bản copy malloc), Length, FilterId, Protocol}
   Protocol = map(NXProtocol → FILTER_PROTOCOL_ICMPV4/V6/TCP/UDP/UNKNOWN/RAW)
   WrIdx = (WrIdx+1) % MAX_PM_PACKETS_IN_QUEUE   (nếu đầy → PmPktQ.WrError++, mất gói)
   SysSystem_NotifyReceivedFilterMatchedPacket()  → set APP_EVENT_RECEIVE_PM_PACKET (event-group App)
        │
[task AppMvl / AppThread_Main]  (app_thread.c:488)
   if (Events & APP_EVENT_RECEIVE_PM_PACKET)  AppThread_HandlePatternMatchedPacket()
        │
AppThread_HandlePatternMatchedPacket (app_thread.c:548):
   ApiSysNetworkPatternMatchedPacketGet(&pPacket, &Length, &PatternId, &Protocol)   ← SysFilter_GetPmPkt (sys_lan_api.c:222)
   if (PatternId == ID_FILTER_STAGE2_HOST_COMMANDS && Protocol == UDP)
        AppHostcmd_via_lan(pPacket, Length)     ← host command qua LAN (thay vì HCI FIFO)
   ApiSysMemFree(pPacket)
```

⚠ `AppThread_HandlePatternMatchedPacket` **chỉ xử lý tường minh** `ID_FILTER_STAGE2_HOST_COMMANDS`.
Pattern Id khác → chỉ `free`. ⇒ đường `PmPktQ` chủ yếu cho **host-command-over-LAN** + offload SDK.
Các proxy LLMNR/NBNS/mDNS/SNMP nhận gói qua **lwIP UDP callback** (T5.3/5.4), KHÔNG qua `PmPktQ`.

`PmPktQ` là **circular queue** `MAX_PM_PACKETS_IN_QUEUE` (`WrIdx`/`RdIdx`), bảo vệ bằng
`SysSystem_MutexSystemLayerApi`. `SysFilter_GetPmPkt` re-notify nếu còn phần tử.

## 6 · Cấu hình filter — IOCTL từ Linux (`app_hostcmd.c:612-690`)

```
Linux net-proxy driver → MSG_CMD_PATTERN (qua HCI FIFO) → AppHostcmd_HandleMsgCmdOfTypePattern:
   MSG_CMD_PATTERN_DEFINE  (MsgPatternConfig: id, stage, Flags, FilterFunctionID, ProtocolType, SubPatternList[])
        → ApiSysSoftwarePatternDefine(&req->pattern, id, stage) → SysApiFilter_Define
   MSG_CMD_PATTERN_ENABLE  → ApiSysSoftwarePatternEnable → SysApiFilter_Enable
   MSG_CMD_PATTERN_DISABLE / DELETE / READ
```
`mvbase_api_pattern.c`: `ApiSysSoftwarePattern{Define,Read,Remove,Enable,Disable}` = wrapper mỏng
lên `SysApiFilter_*`. `SYS_FILTER` và `Pattern` cùng struct.

⇒ **Bộ lọc là do Linux đẩy runtime**, không compile-time. Linux gửi profile filter (proxy nào cần
đánh thức, gói nào forward, gói nào discard) **trước khi host ngủ**.

## 8 · Tóm tắt (theo format skill)

**1. Tồn tại để làm gì:** Bộ lọc gói 2 tầng. **Tầng A** = HW WoL pattern trong GMAC/Iris
(`hal_wol.c`, magic packet + SDK pattern), khớp ở tốc độ dây, đánh thức hệ thống không cần CPU —
dựng bởi `SysSystem_ThreadMain` khi driver Linux vắng. **Tầng B** = SW `SysFilter` chạy trên R4,
2 sub-stage (STAGE_1 raw frame trong `low_level_input`; STAGE_2 payload L4 sau lwIP). Mỗi filter =
danh sách sub-pattern `{offset, value, mask}`; khớp → 4 ActionFlag: FOR_APP_LAYER (→ `PmPktQ` →
`APP_EVENT_RECEIVE_PM_PACKET`), FORWARD_PACKET (→ HCI FIFO Linux), WAKE_SYSTEM (+ `RedirectTraffic=true`),
DISCARD_PACKET. `SysFilter_Init` xoá sạch — **không filter compile-time**; Linux đẩy toàn bộ pattern
runtime qua `MSG_CMD_PATTERN_*` trước khi host ngủ.

**2. Call flow:**
```
── config ──
Linux → MSG_CMD_PATTERN_DEFINE/ENABLE (HCI FIFO) → AppHostcmd_HandleMsgCmdOfTypePattern
   → ApiSysSoftwarePatternDefine → SysApiFilter_Define → SysFilterStage[stage].pFilterList[id]

── runtime (RX, host ngủ) ──
low_level_input (T5.1) → SysFilter_Execute_Filter(frame, len, 0)   [STAGE_1]
   → GetMatchingFilter (duyệt pFilterList, kiểm sub-pattern)
   → ActionFlags:
        FOR_APP_LAYER → memcpy → SysFilter_PutPmPkt → PmPktQ → NotifyReceivedFilterMatchedPacket
                        → APP_EVENT_RECEIVE_PM_PACKET → AppThread_HandlePatternMatchedPacket
                           → [ID_FILTER_STAGE2_HOST_COMMANDS+UDP] AppHostcmd_via_lan
        FORWARD_PACKET → SysApiLan_PacketForwardToDriver (HCI FIFO)
        WAKE_SYSTEM    → SysApiSystem_Wake + RedirectTraffic=true + SYS_EVENT_WAKE_SYSTEM
        DISCARD_PACKET → return RC_DISCARD_PACKET  (không vào lwIP)
   không khớp → RC_OK → lwIP ethernet_input → (proxy qua UDP callback)  [STAGE_2 chạy sau nếu bật]
```
