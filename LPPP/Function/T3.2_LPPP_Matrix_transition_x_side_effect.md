### B014 register (`LPPP_Flash.h:36, 52-67`)
```
B014_ADDRESS = SPI_BASEADDRESS + 0x003FF01C = 0xF43FF01C   (2 byte, trong spi-user)
enum bit:  0..10  B014_ERP_*  (RCV_RET_REQ, ON_PD1, RCV_PD1_PG, OUT_XPONRESET, OUT_POFFISO,
                               RCV_POFFCTL2, ON_PD2, RCV_POFFCTL0, ON_PD3, RCV_PONCTL0_1, ON_PD5)
           11     B014_TO_SLEEP2_OR_ErP     ← TR5/6 set
           12     B014_BEGIN_PHASE6         ← power_cpu resume set (app_scpi.c:289)
           13     B014_TO_SLEEP1            ← TR8/10 set
           14     B014_BIT14
           15     B014_ERP_LOG_EN
```
`Bregister_modify(dst, mask, data)` (`LPPP_FlashSub.c:126`): `flash_read` 2B → `reg &= ~mask;
reg |= data & mask;` → `flash_modify_sub` (chạy từ RAM). Mỗi lần = 1 flash read + 1 RMW
(~chục ms). Đây là **nhật ký breadcrumb phase** cho chuỗi nguồn ErP + sleep — để truy nguyên
khi máy chết giữa chừng.

### PS-CPU I2C (`LPPP_Matrix.c:32-36`)
`LPPP_i2c_write(bus 0, addr 0x3E, reg 0xC0, data 56)` — mã `56` = `PressPanelPowerKeyDeepSleep`.

## 3 · Ba quan sát then chốt

### 3.1 · Toàn bộ "AP power / PIDI / DDR / ATF" đã rời khỏi KM matrix
Mọi TR có khối `#if 0` với ghi chú **"Marvell対応済み"** / **"handled by Marvell side"** —
việc bật/tắt nguồn AP806, PIDI, DDR, copy ATF **chuyển hết sang `pmu_phase()`** phía Marvell
(TR0 `pmu_baseline`→..., `power_cpu` cho core). KM matrix **hiện chỉ còn**:
- GPIO đặc thù KM: `MOTION_EN_MC/IR` (engine), `ENG_STATUS1/2`, `HRESET_REQN` (reset cứng),
  pad mux I2S (33/34)
- Breadcrumb B014 (bit 11/13)
- Cờ flash mất điện (`0xF4377007`/`0xF4378007`)
- QoS reload (UL / MoChi+AP)
- Log I2C tới PS-CPU

### 3.2 · Hai transition dead + hai transition đắt
- **Dead:** `TR1` (SW_OFF@NORMAL), `TR7/9` (SW_OFF@SLEEP2/ErP) — `PWR_SW_OFF` **không có producer**
  (`PowerControlEventManager.md §8.1`). Tắt máy thật = ISR `LPPP_GPIO_CallbackMainSW` kéo `HRESET_REQN=0`.
- **Rẻ:** `TR3` (2 gpio_set_func_sel ~µs).
- **Đắt:** `TR8/10` (I2C ~ms + flash RMW ~chục ms + QoS_SetupMoChi 10 reg + QoS_SetupAP ~15 reg
  + ~25 dòng debug print). Chặn mọi event sau nó trong queue vì `PwEvtMgr` xử lý tuần tự.

### 3.3 · `ap_sd` = biến ghép nối duy nhất giữa 2 TR (khớp `PowerControlEventManager.md §Phần C`)
- `TR5_TR6` **đặt** `ap_sd = NO_BOOT` (lúc vào Sleep2/ErP)
- `TR2b` **đọc** `ap_sd == NO_BOOT` → quyết định reset cứng CA72 khi flicker
- SCPI `0x83` `SCPISetAPStatus(WARP_BOOT)` **giải giáp** (Linux nói "tao boot xong")
- `LPPP_KM_Init` cũng đặt `NO_BOOT` lúc khởi tạo

⚠ `TR2b` **luôn `return NORMAL`** kể cả khi `ap_sd == WARP_BOOT` (không làm gì): state bị ép về
NORMAL mà không có hành động phần cứng → SM và thực tế phần cứng có thể lệch.

## 4 · Tóm tắt (theo format skill)

**1. Tồn tại để làm gì:** `LPPP_Matrix.c` là 11 hàm scenario của máy trạng thái nguồn KM, tra
bởi `fpLPPP_ScenarioFunc[state][event]`. Sau khi phần "AP power/PIDI/DDR/ATF" chuyển sang
`pmu_phase()` Marvell, các TR còn lại chỉ chạm: GPIO KM (MOTION_EN, ENG_STATUS, HRESET_REQN,
pad mux I2S 33/34), breadcrumb B014 (`0xF43FF01C` bit 11/13), cờ mất điện flash
(`0xF4377007`/`0xF4378007` ← `0x10`), QoS reload, và log I2C tới PS-CPU (`0x3E` reg `0xC0`).

**2. Bảng transition × side effect:** §2 (đầy đủ pin/địa chỉ/bit).

**3. File đã tham chiếu:**
- `ApplicationKM/LPPP_Matrix.c` (toàn bộ 476 dòng), `LPPP_Matrix.h`
- `ApplicationKM/LPPP_Gpio.h:24-95`
- `ApplicationKM/LPPP_Flash.h:36-67`, `LPPP_FlashSub.c:126-160`
- `ApplicationKM/LPPP_inc.h:45-56`
- `ApplicationMrvl/Test/app_scpi.c:289` (`B014_BEGIN_PHASE6`)

**4. Đã xác nhận:**
- ✅ `TR1` + `TR7/9` = dead code (`PWR_SW_OFF` không producer).
- ✅ Khối AP power/PIDI/DDR/ATF trong TR0/TR5-6/TR7-9/TR8-10 đều `#if 0` "Marvell対応済み".
- ✅ B014 = 16-bit breadcrumb (`0xF43FF01C`): bit 11 TO_SLEEP2_OR_ErP (TR5/6), bit 12 BEGIN_PHASE6
  (power_cpu resume), bit 13 TO_SLEEP1 (TR8/10), bit 0-10 = sub-phase ErP.
- ✅ Cờ mất điện = `0x10` tại offset `+0x07` của 2 vùng `0xF4377000`/`0xF4378000`.
- ✅ `LPPP_SpiFlashWrite_Ca72wdt_Reboot` ghi 6 lần (3 field × 2 vùng) khi CA72WDT nổ.
- ✅ Pin sản xuất: `MOTION_EN_MC`=71, `MOTION_EN_IR`=72, `AP_PWR_EN`=65, `HRESET_REQN`=66,
  `ENG_STATUS1/2`=192/193, `PANEL_STOP`=49. (`_ESL` redefine = dead.)
